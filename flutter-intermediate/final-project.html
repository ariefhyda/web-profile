Pilihan Tema Project

Pilih salah satu (atau ajukan tema sendiri ke dosen):

  1. 📝 Task Manager App — CRUD tasks, kategori, prioritas, due date. API: JSONPlaceholder (gratis) atau buat backend sendiri pakai Laravel (dari course Laravel).
  2. 📓 Note App — Catatan dengan kategori, search, favorit. Bonus: rich text editor.
  3. 🎬 Movie/Anime Browser — List + detail + favorit lokal. API: TMDB API atau Jikan (anime).
  4. 🛒 Mini E-Commerce — Product list, detail, cart, checkout (mock). API: FakeStoreAPI.
  5. 📚 Personal Library — Track buku yang dibaca, rating, review. API: Google Books.
  6. 🌤️ Weather Dashboard — Cuaca multi-kota dengan favorit. API: OpenWeatherMap.

📦 Setup Project

  • Flutter project baru di-create + add get dependency
  • Jalankan get init — struktur folder siap
  • Git repository + initial commit
  • Test koneksi REST API dengan Postman/Insomnia dulu

🏗️ Arsitektur & Folder

  • Folder data/models berisi model class (fromJson, toJson)
  • Folder data/providers berisi GetConnect/Dio service
  • Folder data/repositories sebagai jembatan provider ↔ controller
  • Folder modules/<fitur> untuk tiap halaman (view + controller + binding)
  • Folder routes/ dengan app_routes.dart + app_pages.dart

📱 Halaman & Fitur

  • Splash Screen dengan logo & init dependency
  • Halaman List — fetch dari API, loading state, error state, empty state
  • Pull-to-refresh di halaman list
  • Halaman Detail — kirim parameter via URL/arguments
  • Form Create — input + validasi + submit ke API
  • Form Edit — pre-filled dari data lama
  • Hapus dengan konfirmasi Get.defaultDialog
  • Search / Filter dengan debounce
  • Snackbar feedback untuk setiap aksi (sukses/gagal)

⚡ GetX Implementation

  • Reactive state dengan .obs + Obx
  • Loading & error state ditangani per controller (bukan global)
  • Setiap halaman punya Binding sendiri
  • Named routes — TIDAK ada hardcoded string
  • Repository pattern: Controller tidak langsung panggil API
  • Worker (debounce/ever) untuk fitur search
  • GetxService untuk dependency global (e.g., ApiClient)

🎨 UI/UX & Polish

  • Theme konsisten (warna, font, spacing)
  • App icon + splash icon (pakai flutter_launcher_icons)
  • Loading indicator (shimmer atau circular progress)
  • Transisi halaman halus (defaultTransition di GetMaterialApp)
  • Responsif: jalan di HP & tablet (cek SafeArea)

📝 Dokumentasi & Submit

  • README.md: deskripsi, screenshot, cara run, API yang dipakai
  • Screenshot ≥ 4 halaman di README
  • APK release di-build dan upload ke Releases GitHub

  10. Custom transition animation di tiap route

Tips dari Senior Developer

  1. Mulai dari yang sederhana. Fokus dulu ke MVP (list + detail). Polish belakangan.
  2. Commit sering ke Git. Setiap fitur kecil = 1 commit. Lebih mudah revert kalau ada bug.
  3. Selalu cek API response sebelum coding model. Buka di Postman, copy JSON, baru bikin class.
  4. Pisahkan logic dari UI sejak awal. Jangan ada http.get di Widget — ini contagious habit.
  5. Pakai const di mana bisa. Setiap widget yang tidak berubah → tambah const. Hemat rebuild.
  6. Testing manual itu wajib. Coba semua skenario: koneksi mati, input kosong, server down.
  7. Documentation = portfolio. README yang bagus = HR baca dengan minat. Sertakan screenshot & video!
