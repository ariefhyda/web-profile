Mengapa Arsitektur Itu Penting?

Aplikasi yang Anda bangun di Fundamentals mungkin sudah jalan — tapi apakah maintainable? Bayangkan skenario ini setelah 3 bulan tidak menyentuh kode:

🏠
Analogi: Dua Rumah

Rumah A: semua barang ditumpuk di satu ruangan — baju di atas piring, sepatu di kasur. Cari kunci? Aduk semuanya. Rumah B: baju di lemari, piring di rak, sepatu di rak sepatu. Cari apapun? Langsung ketemu. Kode tanpa arsitektur = Rumah A. Kode dengan Clean Architecture = Rumah B.

Tanda Kode Anda Butuh Arsitektur

  1. File satu Widget > 500 baris. Scroll terus-menerus untuk menemukan satu fungsi.
  2. setState() dipanggil dari banyak tempat. Sulit memprediksi kapan UI rebuild.
  3. API call ditulis langsung di Widget. Tidak bisa dites, tidak bisa dipakai ulang.
  4. "Prop drilling" — variabel dilempar lewat 5 widget hanya untuk sampai ke widget yang butuh.
  5. Lupa apa yang dilakukan kode Anda sendiri setelah seminggu tidak buka.
  6. Ubah 1 fitur kecil = bug muncul di 3 tempat lain.

Prinsip SOLID (Singkat)

SOLID adalah 5 prinsip desain OOP yang membantu kode tetap rapi. Tidak perlu hafal mati — cukup pahami semangatnya:

HurufNamaInti
SSingle ResponsibilitySatu class = satu pekerjaan. Class UserController jangan ikut handle network.
OOpen/ClosedClass boleh diperluas (extend), tapi tidak boleh dimodifikasi langsung.
LLiskov SubstitutionSubclass harus bisa menggantikan parent class tanpa break code.
IInterface SegregationBanyak interface kecil lebih baik dari satu interface raksasa.
DDependency InversionClass jangan bergantung ke class konkret — bergantung ke abstraksi (interface).

Perbandingan: Spaghetti Code vs Clean Architecture

Lihat sendiri perbedaannya. Kasus: tampilkan daftar user dari API ke layar.

❌ Spaghetti (sulit dipelihara)
class UserPage extends StatefulWidget {
  @override
  _UserPageState createState() => _UserPageState();
}

class _UserPageState extends State<UserPage> {
  List users = [];

  Future fetchUsers() async {
    // Logic data + UI = nyampur
    final response = await http
      .get(Uri.parse('https://api/users'));
    setState(() {
      users = jsonDecode(response.body);
    });
  }

  @override
  Widget build(BuildContext context) {
    fetchUsers(); // API call di build! 😱
    return ListView.builder(...);
  }
}
✅ Clean (terpisah per lapisan)
// 1. data/user_repository.dart
class UserRepository {
  Future<List<User>> fetchUsers() async {
    final r = await http.get(...);
    return User.fromJsonList(r.body);
  }
}

// 2. controllers/user_controller.dart
class UserController extends GetxController {
  final repo = UserRepository();
  final users = <User>[].obs;

  Future loadUsers() async {
    users.value = await repo.fetchUsers();
  }
}

// 3. views/user_page.dart
class UserPage extends StatelessWidget {
  final c = Get.put(UserController());
  Widget build(_) => Obx(() => ListView(...));
}
