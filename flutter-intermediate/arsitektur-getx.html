Modul 3: Arsitektur GetX Pattern

Estimasi: 55 Menit
Teori & Praktikum

Sekarang setelah Anda paham GetX adalah apa, mari pelajari bagaimana mengorganisasi kode menggunakannya. Pola yang direkomendasikan tim GetX adalah GetX Pattern — feature-first dengan 3 komponen utama: View, Controller, Binding.

🎭
Analogi: Pementasan Drama

View = panggung yang dilihat penonton. Controller = sutradara di balik layar yang atur cerita & emosi. Binding = produser yang menyiapkan semua kebutuhan (kostum, properti) sebelum pementasan dimulai. Tiga peran terpisah — semua bekerja sama menghasilkan pertunjukan yang bagus.

Struktur Folder Standar

GetX merekomendasikan feature-first — folder dikelompokkan berdasarkan fitur, bukan per tipe file. Inilah strukturnya:

lib/ ├── main.dart# Entry point + GetMaterialApp + initialRoute ├── app/ │ ├── data/# Lapisan data (terpisah dari fitur) │ │ ├── models/ │ │ │ └── user_model.dart │ │ ├── providers/# API client │ │ │ └── user_provider.dart │ │ └── repositories/ │ │ └── user_repository.dart │ │ │ ├── modules/# Satu folder = satu halaman / fitur │ │ ├── home/ │ │ │ ├── home_view.dart# Widget UI │ │ │ ├── home_controller.dart# State & logic │ │ │ └── home_binding.dart# DI registration │ │ ├── login/ │ │ │ ├── login_view.dart │ │ │ ├── login_controller.dart │ │ │ └── login_binding.dart │ │ └── profile/ │ │ └── ... # pola yang sama │ │ │ ├── routes/ │ │ ├── app_pages.dart# Daftar semua route + binding │ │ └── app_routes.dart# Konstanta route name │ │ │ └── utils/ │ ├── constants.dart │ └── themes.dart
Kenapa Feature-first?

Saat kerja di fitur "Login", semua file relevan ada di satu folder modules/login/. Tidak perlu lompat ke controllers/, views/, bindings/ yang berbeda-beda. Hemat waktu, mudah refactor — kalau fitur Login dihapus, tinggal hapus 1 folder.

Contoh Lengkap: Module Home

1. Controller (Logic & State)

modules/home/home_controller.dart 
import 'package:get/get.dart';
import '../../data/repositories/user_repository.dart';
import '../../data/models/user_model.dart';

class HomeController extends GetxController {
  // Repository di-inject lewat constructor
  final UserRepository _repo;
  HomeController(this._repo);

  // State (reactive)
  final users = <User>[].obs;
  final isLoading = false.obs;
  final errorMessage = ''.obs;

  @override
  void onInit() {
    super.onInit();
    fetchUsers(); // Auto-load saat controller dibuat
  }

  Future<void> fetchUsers() async {
    try {
      isLoading.value = true;
      users.value = await _repo.getAll();
    } catch (e) {
      errorMessage.value = e.toString();
    } finally {
      isLoading.value = false;
    }
  }

  void deleteUser(int id) {
    users.removeWhere((u) => u.id == id);
  }
}

2. View (UI)

modules/home/home_view.dart 
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'home_controller.dart';

// 👇 GetView = ada properti `controller` otomatis
class HomeView extends GetView<HomeController> {
  const HomeView({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Home')),

      // 👇 Obx() = rebuild otomatis saat data .obs berubah
      body: Obx(() {
        if (controller.isLoading.value) {
          return const Center(child: CircularProgressIndicator());
        }
        if (controller.errorMessage.isNotEmpty) {
          return Center(child: Text(controller.errorMessage.value));
        }
        return ListView.builder(
          itemCount: controller.users.length,
          itemBuilder: (_, i) => ListTile(
            title: Text(controller.users[i].name),
            trailing: IconButton(
              icon: const Icon(Icons.delete),
              onPressed: () => controller.deleteUser(controller.users[i].id),
            ),
          ),
        );
      }),

      floatingActionButton: FloatingActionButton(
        onPressed: () => controller.fetchUsers(),
        child: const Icon(Icons.refresh),
      ),
    );
  }
}

3. Binding (Dependency Injection)

modules/home/home_binding.dart 
import 'package:get/get.dart';
import 'home_controller.dart';
import '../../data/repositories/user_repository.dart';

class HomeBinding extends Bindings {
  @override
  void dependencies() {
    // Daftarkan dependency yang dibutuhkan halaman Home
    Get.lazyPut<UserRepository>(() => UserRepository());
    Get.lazyPut<HomeController>(
      () => HomeController(Get.find<UserRepository>()),
    );
  }
}

4. Mendaftarkan Route dengan Binding

routes/app_pages.dart 
import 'package:get/get.dart';
import '../modules/home/home_view.dart';
import '../modules/home/home_binding.dart';
import 'app_routes.dart';

class AppPages {
  static final List<GetPage> routes = [
    GetPage(
      name: Routes.HOME,
      page: () => const HomeView(),
      binding: HomeBinding(), // 👈 binding di-attach ke route
    ),
    GetPage(
      name: Routes.LOGIN,
      page: () => const LoginView(),
      binding: LoginBinding(),
    ),
  ];
}
routes/app_routes.dart 
// Konstanta untuk nama route — hindari typo!
abstract class Routes {
  static const HOME = '/home';
  static const LOGIN = '/login';
  static const PROFILE = '/profile';
}

5. Daftarkan di main.dart

main.dart 
void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'My App',
      initialRoute: Routes.HOME,         // halaman pertama
      getPages: AppPages.routes,         // daftar semua halaman
      defaultTransition: Transition.fade,
    );
  }
}

Lifecycle Controller

GetxController punya 3 method lifecycle yang bisa di-override. Pahami kapan masing-masing dipanggil:

MethodKapan DipanggilCocok untuk
onInit()Saat controller pertama kali dibuat (sebelum widget tampil)Fetch data awal, init listener
onReady()1 frame setelah widget pertama kali tampilTampilkan dialog/snackbar setelah load
onClose()Saat controller dihapus dari memoryCancel stream, dispose controller text
contoh lifecycle 
class ChatController extends GetxController {
  final messages = <Message>[].obs;
  StreamSubscription? _sub;
  TextEditingController? textCtrl;

  @override
  void onInit() {
    super.onInit();
    textCtrl = TextEditingController();
    _sub = chatService.stream.listen((m) => messages.add(m));
  }

  @override
  void onReady() {
    super.onReady();
    if (messages.isEmpty) {
      Get.snackbar('Info', 'Belum ada pesan');
    }
  }

  @override
  void onClose() {
    _sub?.cancel(); // hindari memory leak!
    textCtrl?.dispose();
    super.onClose();
  }
}

GetView vs StatelessWidget Manual

Anda bisa pakai StatelessWidget biasa, tapi GetView lebih ringkas:

😐 StatelessWidget biasa
class HomeView extends StatelessWidget {
  @override
  Widget build(_) {
    final controller = Get.find<HomeController>();
    return Scaffold(
      body: Obx(() => Text('${controller.count}')),
    );
  }
}
✨ GetView
class HomeView extends GetView<HomeController> {
  @override
  Widget build(_) {
    return Scaffold(
      body: Obx(() => Text('${controller.count}')),
      // ⬆ "controller" otomatis tersedia,
      //   tidak perlu Get.find sendiri
    );
  }
}
Konvensi Penamaan

Ikuti konvensi: FiturView + FiturController + FiturBinding. Misal: LoginView, LoginController, LoginBinding. Konsisten = mudah dibaca tim.
