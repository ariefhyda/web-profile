Modul 5: State Management dengan GetX

Estimasi: 65 Menit
Teori & Demo

Inilah jantung GetX. Bagaimana data berubah, dan bagaimana UI bereaksi terhadap perubahan tersebut. GetX menawarkan 2 pendekatan: Reactive (otomatis) dan Simple (manual). Anda akan menggunakan keduanya — bergantung kebutuhan.

💡
Analogi: Lampu Sensor vs Lampu Saklar

Reactive (lampu sensor): data berubah → UI otomatis update. Tidak perlu kasih perintah. Simple (lampu saklar): data berubah, tapi UI baru update setelah Anda panggil update() manual. Sensor = lebih nyaman, saklar = lebih hemat listrik (resource).

Reactive State (Rx + Obx)

Reactive state pakai 3 elemen: variabel .obs, method untuk mengubahnya, dan widget Obx() yang dengar perubahan.

counter_controller.dart 
class CounterController extends GetxController {
  // 1️⃣ Buat variabel reactive dengan .obs
  final count = 0.obs;          // RxInt
  final name = ''.obs;          // RxString
  final isLoading = false.obs;  // RxBool
  final items = <String>[].obs; // RxList

  // 2️⃣ Method untuk ubah nilai
  void increment() {
    count.value++; // → otomatis trigger UI update
    // atau singkatnya: count++;
  }
}
counter_view.dart 
class CounterView extends GetView<CounterController> {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Column(
        children: [
          // 3️⃣ Bungkus dengan Obx() agar reaktif
          Obx(() => Text('Count: ${controller.count}')),

          // Widget di luar Obx() TIDAK akan rebuild
          Text('Static text'),

          ElevatedButton(
            onPressed: controller.increment,
            child: Text('+'),
          ),
        ],
      ),
    );
  }
}

Simple State Management (GetBuilder)

Lebih hemat resource dari Rx (tidak ada stream), cocok untuk state yang jarang berubah atau di project tanpa hot reload aggresif.

⚡ Reactive (Rx + Obx)
// Controller
class Ctrl extends GetxController {
  final count = 0.obs;
  void inc() => count++;
}

// View — otomatis update
Obx(() => Text('${c.count}'))

// ✓ Auto update
// ✗ Sedikit lebih berat (Stream)
🪶 Simple (GetBuilder)
// Controller — TIDAK pakai .obs
class Ctrl extends GetxController {
  int count = 0;
  void inc() {
    count++;
    update(); // 👈 manual trigger
  }
}

// View — pakai GetBuilder
GetBuilder<Ctrl>(
  builder: (c) => Text('${c.count}'),
)

// ✓ Lebih ringan
// ✗ Manual update()

Worker — Listen Perubahan Tertentu

Workers adalah listener bawaan GetX yang menjalankan fungsi saat variabel Rx berubah. Berguna untuk efek samping (logging, debounce, dll).

WorkerTujuanContoh Pemakaian
everSetiap kali value berubahLog analytics tiap step
onceHanya saat pertama berubahTutup splash screen
debounceTunggu X detik setelah berhenti berubahSearch box (hindari API spam)
intervalMaksimal 1x per X detikThrottle scroll event
contoh workers 
class SearchController extends GetxController {
  final query = ''.obs;
  final results = <Product>[].obs;

  @override
  void onInit() {
    super.onInit();

    // Tunggu user berhenti ketik 500ms, baru cari
    debounce(query, (_) => search(), time: Duration(milliseconds: 500));

    // Log setiap perubahan
    ever(query, (val) => print('Query: $val'));

    // Cek 1x saat results pertama kali ada isi
    once(results, (r) {
      if (r.isNotEmpty) {
        Get.snackbar('Yay', 'Pencarian pertama sukses!');
      }
    });
  }

  Future<void> search() async {
    results.value = await repo.search(query.value);
  }
}

Anti-Pattern: Hindari Ini!

Kesalahan Umum

1) Lupa .value saat update Rx custom. 2) Bungkus seluruh Scaffold dengan Obx (rebuild seluruh halaman). 3) Pakai Obx tanpa ada variabel .obs di dalamnya → error "Obx improperly used". 4) Manipulasi langsung property object Rx (pakai refresh() jika perlu).

❌ Salah
// Bungkus terlalu lebar
Obx(() => Scaffold(
  appBar: AppBar(title: Text('App')),
  body: Column(
    children: [
      Text('${c.count}'), // 👈 cuma ini yg reactive
      // Tapi seluruh Scaffold rebuild! 🤦
    ],
  ),
))
✅ Benar
// Bungkus seminimal mungkin
Scaffold(
  appBar: AppBar(title: Text('App')),
  body: Column(
    children: [
      Obx(() => Text('${c.count}')),
      // ✓ Hanya Text yang rebuild
    ],
  ),
)
