Modul 6: Routing & Middleware

Estimasi: 55 Menit
Teori & Praktikum

Salah satu fitur GetX yang paling disukai: navigasi tanpa context. Anda bisa pindah halaman, lempar parameter, atau push dialog dari mana saja — Controller, Service, bahkan dari background task. Plus, sistem middleware-nya jauh lebih simpel daripada Navigator 2.0.

🗺️
Analogi: GPS vs Peta Lipat

Navigator manual = peta lipat. Anda harus tahu posisi (context), buka peta, cari jalan. GetX routing = GPS. "Anter saya ke /profile" — selesai. Tidak peduli posisi saat ini. Hemat banyak baris kode.

Navigasi Dasar

Ada dua cara navigasi di GetX: direct push (lempar widget langsung) dan named route (pakai nama yang sudah didaftarkan).

😐 Cara Navigator Klasik
// Push
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (_) => DetailPage(),
  ),
);

// Named route
Navigator.pushNamed(context, '/detail');

// Pop
Navigator.pop(context);

// 👎 Butuh context di mana-mana
✨ Cara GetX
// Push
Get.to(() => DetailPage());

// Named route
Get.toNamed('/detail');

// Pop
Get.back();

// 👍 Tanpa context
// 👍 Bisa dipanggil dari Controller
// 👍 Lebih singkat

Method Navigasi Lengkap

MethodPadanan NavigatorFungsi
Get.to(Page())pushPush halaman baru, halaman lama tetap di stack
Get.toNamed("/x")pushNamedPush pakai nama route
Get.off(Page())pushReplacementGanti halaman saat ini (halaman lama hilang)
Get.offAll(Page())pushAndRemoveUntilHapus seluruh stack, jadikan halaman ini root
Get.back()popKembali ke halaman sebelumnya
Get.back(result: data)pop dengan dataKembali sambil kirim data
Get.until((r) => r.name == '/home')popUntilPop sampai ketemu route tertentu

Setup Named Routes (Wajib untuk Project Beneran)

Hardcode Get.toNamed('/detail') rentan typo. Pakai konstanta:

app/routes/app_routes.dart 
// Konstanta nama route
abstract class Routes {
  static const SPLASH = '/';
  static const LOGIN = '/login';
  static const HOME = '/home';
  static const PROFILE = '/profile';
  static const POST_DETAIL = '/post/:id'; // dengan parameter
}
app/routes/app_pages.dart 
class AppPages {
  static final List<GetPage> routes = [
    GetPage(
      name: Routes.SPLASH,
      page: () => const SplashView(),
      binding: SplashBinding(),
    ),
    GetPage(
      name: Routes.LOGIN,
      page: () => const LoginView(),
      binding: LoginBinding(),
      transition: Transition.fadeIn,        // kustom transisi
      transitionDuration: Duration(milliseconds: 300),
    ),
    GetPage(
      name: Routes.HOME,
      page: () => const HomeView(),
      binding: HomeBinding(),
      middlewares: [AuthMiddleware()],       // proteksi route
    ),
    GetPage(
      name: Routes.POST_DETAIL,
      page: () => const PostDetailView(),
      binding: PostDetailBinding(),
    ),
  ];
}

Passing Parameter Antar Halaman

Cara 1: Arguments (Object/Map)

arguments 
// 1. Kirim — bisa Map, atau object apapun
Get.toNamed(Routes.PROFILE, arguments: {
  'userId': 42,
  'name': 'Arif',
});

// 2. Terima di halaman tujuan
class ProfileView extends StatelessWidget {
  @override
  Widget build(_) {
    final args = Get.arguments as Map;
    final userId = args['userId'];
    final name   = args['name'];
    return Text('Halo $name (ID: $userId)');
  }
}

Cara 2: URL Parameter (Lebih RESTful)

URL parameter 
// Definisi route dengan placeholder :id
GetPage(name: '/post/:id', page: () => PostDetailView()),

// Kirim
Get.toNamed('/post/42');
// Atau: Get.toNamed('/post/${post.id}');

// Terima
final id = Get.parameters['id']; // '42'

// Query string
Get.toNamed('/search?q=flutter&page=2');
// Terima
final q    = Get.parameters['q'];
final page = Get.parameters['page'];

Cara 3: Async Result (Tunggu Halaman Balik)

async result 
// Di halaman A
final result = await Get.toNamed('/picker');
print(result); // 'apel'

// Di halaman B (picker)
ElevatedButton(
  onPressed: () => Get.back(result: 'apel'),
  child: Text('Pilih Apel'),
)

Middleware — Auth Guard

Middleware adalah filter yang dijalankan sebelum halaman dimuat. Tipikal: cek login, cek role, redirect, atau logging. GetX punya 5 method override.

MethodKapan DipanggilUse Case
redirect()Sebelum halaman dimuatAuth guard, role check
onPageCalled()Saat route dipanggil (sebelum binding)Modifikasi halaman
onBindingsStart()Sebelum Binding.dependencies() jalanPersiapan dependency tambahan
onPageBuildStart()Sebelum widget di-buildLogging
onPageDispose()Saat halaman ditutupCleanup khusus halaman
middleware/auth_middleware.dart 
import 'package:get/get.dart';
import 'package:flutter/material.dart';

class AuthMiddleware extends GetMiddleware {
  @override
  int? get priority => 1; // urutan eksekusi (lebih rendah duluan)

  @override
  RouteSettings? redirect(String? route) {
    // Cek apakah user sudah login
    final auth = Get.find<AuthService>();

    if (!auth.isLoggedIn) {
      // Belum login → redirect ke login
      return const RouteSettings(name: Routes.LOGIN);
    }

    return null; // null = lanjut ke halaman tujuan
  }
}
attach ke route 
GetPage(
  name: Routes.DASHBOARD,
  page: () => DashboardView(),
  binding: DashboardBinding(),
  middlewares: [
    AuthMiddleware(),         // dijalankan pertama
    RoleAdminMiddleware(),    // lalu yang ini
    AnalyticsMiddleware(),    // terakhir
  ],
),

Bottom Navigation dengan GetX

Untuk app dengan tab bar di bawah, pakai IndexedStack + Obx untuk track tab aktif:

main_view.dart 
class MainController extends GetxController {
  final currentIndex = 0.obs;
  void changeTab(int i) => currentIndex.value = i;
}

class MainView extends GetView<MainController> {
  final pages = [HomeView(), SearchView(), ProfileView()];

  @override
  Widget build(_) {
    return Scaffold(
      body: Obx(() => IndexedStack(
        index: controller.currentIndex.value,
        children: pages,
      )),
      bottomNavigationBar: Obx(() => BottomNavigationBar(
        currentIndex: controller.currentIndex.value,
        onTap: controller.changeTab,
        items: [...],
      )),
    );
  }
}
