Modul 5: Lifecycle & Manajemen Container

Estimasi: 40 Menit
Praktikum

Sebuah container melewati beberapa status selama hidupnya: dibuat, berjalan, di-pause, berhenti, hingga dihapus. Memahami transisi antar status — dan perintah mana yang sah pada status tertentu — adalah inti dari mengelola container sehari-hari.

1. Status Container

  1. Created — Container sudah dibuat dari image (docker create) tetapi belum dijalankan.
  2. Running — Proses utama container sedang berjalan (docker run / start).
  3. Paused — Proses dibekukan sementara (docker pause); memori tetap dipertahankan.
  4. Exited / Stopped — Proses berhenti (docker stop). Data di dalam container masih ada dan bisa di-start lagi.
  5. Removed — Container dihapus permanen (docker rm). Lapisan writable-nya hilang.

2. Simulasi State Machine

Coba kelola siklus hidup container web di bawah. Tombol yang tidak valid akan otomatis nonaktif sesuai status saat ini — misalnya Anda tidak bisa rm container yang sedang running (harus di-stop dulu). Amati log untuk melihat perintah yang dijalankan.

stop vs rm

stop hanya menghentikan proses — container & datanya tetap ada, bisa dihidupkan lagi. rm menghapus container beserta lapisan writable-nya. Inilah mengapa data penting tidak boleh disimpan di dalam container (bahas di modul Volume).
