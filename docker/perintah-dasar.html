Modul 3: Instalasi & Perintah Dasar

Estimasi: 45 Menit
Praktikum

Bagian ini membahas cara memasang Docker, lalu langsung berlatih perintah-perintah paling fundamental. Di akhir modul tersedia terminal simulasi agar Anda dapat mencoba perintah tanpa takut merusak apa pun.

1. Instalasi Docker

  1. Windows & macOS — Pasang Docker Desktop dari situs resmi docker.com. Aplikasi ini sudah mencakup Docker Engine, CLI, dan Docker Compose dalam satu paket berbasis GUI.
  2. Linux (Ubuntu/Debian) — Pasang Docker Engine via repositori resmi. Setelah selesai, tambahkan user Anda ke grup docker agar tidak perlu sudo setiap kali.
  3. Verifikasi — Jalankan docker --version dan docker run hello-world untuk memastikan instalasi sukses.
install-linux.sh 
# Script resmi convenience installer dari Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# Agar bisa pakai docker tanpa sudo (login ulang setelahnya)
sudo usermod -aG docker $USER

# Verifikasi
docker --version

2. Anatomi Sebuah Perintah Docker

Hampir semua perintah Docker mengikuti pola yang konsisten:

pola perintah 
docker <perintah> [OPTIONS] <image/container> [argumen]

# contoh:
docker run -d -p 8080:80 --name web nginx

3. Daftar Perintah Wajib

PerintahFungsi
docker pull <img>Mengunduh image dari registry ke lokal
docker imagesMenampilkan daftar image lokal
docker run <img>Membuat & menjalankan container dari image
docker psDaftar container yang sedang berjalan
docker ps -aDaftar semua container (termasuk yang berhenti)
docker stop <id>Menghentikan container yang berjalan
docker rm <id>Menghapus container (harus berhenti dulu)
docker rmi <img>Menghapus image dari lokal

4. Terminal Latihan (Simulasi)

Cobalah langsung! Ketik perintah lalu tekan Enter, atau klik salah satu chip untuk menjalankannya otomatis. Terminal ini menyimpan state sederhana — image yang Anda pull dan container yang Anda run akan benar-benar muncul di docker images dan docker ps.
