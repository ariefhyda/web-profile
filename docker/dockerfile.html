Modul 4: Docker Image & Dockerfile

Estimasi: 50 Menit
Teori & Praktikum

Image adalah cetak biru container. Untuk membuat image sendiri, kita menulis sebuah Dockerfile: berkas teks berisi instruksi yang dieksekusi daemon secara berurutan. Hal terpenting yang harus dipahami adalah konsep layer dan cache — keduanya menentukan cepat-lambatnya build Anda.

1. Image Terdiri dari Layer

Setiap instruksi di Dockerfile menghasilkan satu layer baru yang ditumpuk di atas layer sebelumnya. Layer bersifat read-only dan bisa dibagi-pakai antar image. Saat container berjalan, Docker menambahkan satu lapisan tipis writable di paling atas.

2. Instruksi Dockerfile Penting

InstruksiKegunaan
FROMImage dasar (base image), wajib ada paling awal
WORKDIRSet direktori kerja di dalam image
COPY / ADDSalin file dari host ke image
RUNJalankan perintah saat build (mis. install dependency)
EXPOSEDokumentasi port yang dipakai container
ENVSet environment variable
CMD / ENTRYPOINTPerintah default saat container dijalankan

3. Simulasi Build & Layer Cache

Klik Build untuk membangun image dari nol — perhatikan tiap instruksi menjadi satu layer. Lalu coba rebuild setelah mengubah kode: layer yang tidak berubah akan diambil dari CACHE (instan), sedangkan layer yang berubah dibangun ulang beserta semua layer di bawahnya.

                    Aturan Emas Cache
                

                
Begitu satu layer berubah, semua layer di bawahnya ikut dibangun ulang — cache di bawahnya batal. Maka taruh instruksi yang jarang berubah di atas, dan yang sering berubah (kode aplikasi) di bawah.

            


            
4. Membangun & Menjalankan

            

                

                    

                    terminal
                    
                

                
# Bangun image dari Dockerfile di folder saat ini (.)
docker build -t myapp:1.0 .

# Jalankan container dari image yang baru dibuat
docker run -d -p 3000:3000 myapp:1.0
