Modul 8: Docker Compose

Estimasi: 50 Menit
Praktikum

Aplikasi nyata jarang terdiri dari satu container. Biasanya ada web server, backend API, database, cache, dan lainnya. Menjalankan semuanya satu per satu dengan docker run panjang itu melelahkan dan rawan salah. Docker Compose memungkinkan kita mendefinisikan seluruh stack dalam satu berkas docker-compose.yml, lalu menjalankannya dengan satu perintah.

1. Berkas docker-compose.yml

docker-compose.yml 
services:
  db:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: secret
    volumes:
      - dbdata:/var/lib/postgresql/data
  api:
    build: ./api
    depends_on:
      - db
  web:
    image: nginx
    ports:
      - "8080:80"
    depends_on:
      - api

volumes:
  dbdata:

2. Simulasi compose up

Klik compose up dan amati: Compose menghormati depends_on sehingga service dinyalakan dalam urutan yang benar — db → api → web. Semua otomatis tergabung dalam satu jaringan, sehingga bisa saling memanggil lewat nama service. Coba juga ubah jumlah replika web.

Compose Orchestrator

🔗 Semua service berada di satu network default. Service api dapat terhubung ke database cukup dengan hostname db — tidak perlu IP.

3. Perintah Compose Penting

PerintahFungsi
docker compose up -dJalankan seluruh service di background
docker compose downHentikan & hapus semua container + network
docker compose psStatus service dalam project
docker compose logs -fPantau log semua service secara real-time
docker compose up --buildBuild ulang image sebelum menjalankan
