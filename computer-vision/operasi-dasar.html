Modul 3: Operasi Dasar Citra

Estimasi: 70 Menit
Teori, Simulasi & Praktikum

Setelah memahami representasi citra digital, langkah berikutnya adalah menguasai operasi dasar yang dapat diterapkan pada citra. Operasi-operasi ini menjadi fondasi bagi seluruh teknik pemrosesan citra yang lebih kompleks — mulai dari peningkatan kualitas hingga deteksi objek.

Kategori Operasi Citra

Operasi dasar pada citra umumnya dibagi menjadi tiga kategori utama berdasarkan domain kerjanya:

  1. Operasi Aritmatika
    Operasi penjumlahan, pengurangan, perkalian, dan pembagian antar pixel. Berguna untuk penggabungan citra, perubahan kecerahan/kontras, dan deteksi perbedaan (image differencing).
  2. Operasi Logika
    Operasi bitwise: AND, OR, XOR, NOT. Sering dipakai untuk masking, ekstraksi ROI, dan kombinasi citra biner.
  3. Transformasi Geometri
    Operasi yang mengubah posisi atau bentuk pixel: translasi, rotasi, scaling, flipping, dan affine/perspective transform.

1. Operasi Aritmatika

Operasi aritmatika dilakukan pixel-by-pixel. Perhatikan bahwa OpenCV menggunakan saturated arithmetic — nilai yang melebihi 255 akan dipotong (clipped) menjadi 255, dan nilai negatif menjadi 0. Hal ini berbeda dengan NumPy yang menggunakan modulo arithmetic (255 + 1 = 0).

arithmetic_ops.py 
import cv2
import numpy as np

img1 = cv2.imread('foto1.jpg')
img2 = cv2.imread('foto2.jpg')

# Pastikan ukuran sama
img2 = cv2.resize(img2, (img1.shape[1], img1.shape[0]))

# 1. Penambahan kecerahan (brightness +50)
brighter = cv2.add(img1, np.array([50.0]))

# 2. Blending dua citra (weighted sum)
blended = cv2.addWeighted(img1, 0.7, img2, 0.3, 0)

# 3. Image differencing (deteksi perubahan)
diff = cv2.absdiff(img1, img2)

# 4. Perkalian kontras (contrast x1.5)
contrast = cv2.convertScaleAbs(img1, alpha=1.5, beta=0)

cv2.imshow('Blended', blended)
cv2.waitKey(0)

2. Operasi Logika (Bitwise)

Operasi bitwise sering dipakai untuk masking — misalnya hanya menampilkan region tertentu dari citra. Mask biasanya berupa citra biner (hitam/putih) di mana pixel putih (255) menandakan area yang dipertahankan.

bitwise_masking.py 
import cv2
import numpy as np

img = cv2.imread('foto.jpg')
h, w = img.shape[:2]

# Buat mask berbentuk lingkaran di tengah citra
mask = np.zeros((h, w), dtype=np.uint8)
cv2.circle(mask, (w//2, h//2), 120, 255, -1)

# Operasi AND: hanya tampilkan area mask
masked = cv2.bitwise_and(img, img, mask=mask)

# Operasi NOT: invers citra (negatif)
inverted = cv2.bitwise_not(img)

# Operasi OR / XOR untuk kombinasi mask
mask2 = np.zeros((h, w), dtype=np.uint8)
cv2.rectangle(mask2, (50,50), (200,200), 255, -1)
combined = cv2.bitwise_or(mask, mask2)

3. Transformasi Geometri

Transformasi geometri mengubah posisi spasial pixel tanpa mengubah nilai intensitasnya. Operasi-operasi penting:

  1. Translasi
    Memindahkan citra sejauh (tx, ty) pixel. Menggunakan matriks transformasi 2×3: M = [[1,0,tx],[0,1,ty]].
  2. Rotasi
    Memutar citra sebesar θ derajat terhadap titik pusat tertentu. cv2.getRotationMatrix2D menghasilkan matriks rotasi.
  3. Scaling (Resize)
    Mengubah ukuran citra. Interpolasi yang umum: INTER_LINEAR (default), INTER_CUBIC (kualitas lebih baik, lebih lambat), INTER_NEAREST (paling cepat, kotak-kotak).
  4. Flipping
    Membalik citra secara horizontal (flipCode=1), vertikal (flipCode=0), atau keduanya (flipCode=-1).
  5. Affine & Perspective Transform
    Affine: mempertahankan paralelitas garis (3 titik referensi). Perspective: memungkinkan koreksi distorsi sudut pandang (4 titik referensi).
geometric_transform.py 
import cv2
import numpy as np

img = cv2.imread('foto.jpg')
h, w = img.shape[:2]

# 1. Translasi 50 px ke kanan, 30 px ke bawah
M_tr = np.float32([[1, 0, 50], [0, 1, 30]])
translated = cv2.warpAffine(img, M_tr, (w, h))

# 2. Rotasi 45 derajat terhadap pusat citra
M_rot = cv2.getRotationMatrix2D((w/2, h/2), 45, scale=1.0)
rotated = cv2.warpAffine(img, M_rot, (w, h))

# 3. Resize (scale 0.5x)
resized = cv2.resize(img, None,
                     fx=0.5, fy=0.5,
                     interpolation=cv2.INTER_CUBIC)

# 4. Flip horizontal
flipped = cv2.flip(img, 1)

# 5. Perspective transform (koreksi sudut pandang)
src = np.float32([[50,50],[300,80],[30,280],[320,300]])
dst = np.float32([[0,0],[300,0],[0,300],[300,300]])
M_persp = cv2.getPerspectiveTransform(src, dst)
warped = cv2.warpPerspective(img, M_persp, (300, 300))
Tip: Border Mode

Saat melakukan rotasi/translasi, pixel di luar citra asli akan kosong. Gunakan parameter borderMode dengan nilai BORDER_REFLECT, BORDER_REPLICATE, atau BORDER_CONSTANT (dengan borderValue) untuk mengontrol bagaimana pixel kosong tersebut diisi.
