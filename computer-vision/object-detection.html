Modul 9: Object Detection (YOLO)

Estimasi: 90 Menit
Teori, Simulasi & Praktikum

Object detection adalah task Computer Vision yang menjawab dua pertanyaan sekaligus: "Apa objek di citra?" dan "Di mana lokasinya?". Outputnya adalah bounding box (kotak pembatas) plus label kelas untuk setiap objek yang terdeteksi. Berbeda dengan klasifikasi yang hanya memberi satu label per citra.

Klasifikasi vs Localization vs Detection

  1. Image Classification
    Satu citra → satu label kelas. Contoh: "kucing".
  2. Classification + Localization
    Satu citra → satu label + satu bounding box. Asumsi: hanya satu objek per citra.
  3. Object Detection
    Satu citra → banyak bounding box + label untuk setiap objek. Inilah task yang paling realistis.
  4. Instance Segmentation
    Object detection + pixel-level mask untuk setiap instance. Dibahas di modul Segmentation.

Two-Stage vs One-Stage Detector

Pendekatan modern object detection terbagi dua kategori:

  1. Two-Stage (R-CNN family)
    Tahap 1: usulkan region kandidat (Region Proposal). Tahap 2: klasifikasikan dan refine bounding box. Contoh: R-CNN, Fast R-CNN, Faster R-CNN. Akurat tapi lambat.
  2. One-Stage (YOLO, SSD, RetinaNet)
    Langsung prediksi class + bounding box dari fitur citra dalam satu kali forward pass. Lebih cepat, ideal untuk real-time.

YOLO — You Only Look Once

Diperkenalkan oleh Joseph Redmon (2016). Idenya: bagi citra menjadi grid S×S, lalu setiap cell bertanggung jawab memprediksi B bounding box + confidence + class probability untuk objek yang pusatnya jatuh di cell tersebut.

Output YOLO untuk satu cell: vektor [x, y, w, h, conf, p_class_1, ..., p_class_n]. Untuk grid 7×7 dengan 2 box dan 20 kelas, totalnya 7×7×30 = 1470 nilai.

Evolusi YOLO:

  1. YOLOv1 (2016) — konsep awal, akurat tapi lemah pada objek kecil.
  2. YOLOv2/v3 (2017–2018) — anchor box, multi-scale prediction (3 skala), Darknet-53.
  3. YOLOv4/v5 (2020) — CSPDarknet, mosaic augmentation, fokus pada akurasi & kecepatan.
  4. YOLOv7 / YOLOv8 / YOLOv11 (2022–2024) — anchor-free, multi-task (detect, segment, pose). Distribusi paket modern: Ultralytics.

Konsep Kunci: IoU & NMS

IoU (Intersection over Union) mengukur seberapa baik dua bounding box saling tumpang tindih. Nilainya 0 (tidak overlap) hingga 1 (identik). IoU adalah dasar dari evaluasi (mAP) dan pemilihan box (NMS).

Non-Maximum Suppression (NMS) adalah post-processing untuk menghilangkan bounding box duplikat. Algoritmanya:

  1. Urutkan semua box berdasarkan confidence dari tertinggi ke terendah.
  2. Ambil box dengan confidence tertinggi sebagai "winner" — simpan ke output.
  3. Hapus semua box lain yang memiliki IoU dengan winner > threshold (mis. 0.5).
  4. Ulangi dari langkah 2 hingga tidak ada box tersisa.

Metrik Evaluasi: mAP

mAP (mean Average Precision) adalah metrik standar untuk object detection. Dihitung dengan langkah:

  1. Untuk setiap kelas, urutkan prediksi berdasarkan confidence.
  2. Tentukan setiap prediksi sebagai TP atau FP berdasarkan IoU dengan ground truth (threshold mis. 0.5).
  3. Plot precision-recall curve, hitung Average Precision (AP) = area di bawah kurva.
  4. mAP = rata-rata AP semua kelas. mAP@0.5 = IoU threshold 0.5; mAP@[.5:.95] = rata-rata pada threshold 0.5 hingga 0.95.

Praktikum: YOLO dengan Ultralytics

pip install ultralytics opencv-python
yolo_inference.py 
from ultralytics import YOLO
import cv2

# 1. Load pretrained model (otomatis download dari Ultralytics)
#    Pilihan: yolov8n (nano), yolov8s (small), yolov8m, yolov8l, yolov8x
model = YOLO('yolov8n.pt')

# 2. Inference pada gambar
results = model('street.jpg', conf=0.25, iou=0.45)

# 3. Akses hasil deteksi
for r in results:
    boxes = r.boxes
    for box in boxes:
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        conf = box.conf[0].item()
        cls  = int(box.cls[0])
        label = model.names[cls]
        print(f"{label}: {conf:.2f} at [{x1:.0f},{y1:.0f},{x2:.0f},{y2:.0f}]")

# 4. Simpan hasil dengan annotation
for r in results:
    annotated = r.plot()  # BGR numpy array dengan box + label
    cv2.imwrite('output.jpg', annotated)

# 5. Inference pada video / webcam
results = model('video.mp4', stream=True, save=True)
for r in results:
    pass  # proses frame-by-frame

Training pada Dataset Custom

train_custom.py 
# Struktur folder dataset (format YOLO):
# dataset/
#   ├── images/{train,val}/*.jpg
#   ├── labels/{train,val}/*.txt  → class x_center y_center w h (normalized)
#   └── data.yaml

# data.yaml
# path: ./dataset
# train: images/train
# val:   images/val
# names: [helm, rompi, sepatu]

from ultralytics import YOLO

model = YOLO('yolov8n.pt')   # transfer learning dari pretrained

results = model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    name='ppe_detector',
    patience=20      # early stopping
)

# Evaluasi pada validation set
metrics = model.val()
print(f"mAP@0.5     = {metrics.box.map50:.3f}")
print(f"mAP@0.5:.95 = {metrics.box.map:.3f}")
Tools Anotasi

Untuk membuat label bounding box, gunakan tool seperti LabelImg, Roboflow, atau CVAT. Format YOLO menggunakan koordinat ternormalisasi (0–1): <class_id> <x_center> <y_center> <width> <height>.
