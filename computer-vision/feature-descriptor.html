Modul 7: Feature Descriptor (HOG, SIFT, ORB)

Estimasi: 85 Menit
Teori & Praktikum

Feature descriptor adalah representasi numerik yang mendeskripsikan karakteristik lokal pada sebuah titik di citra. Dua citra yang berbeda dapat dibandingkan dengan mencari kemiripan descriptor — fondasi untuk task seperti image matching, object recognition, panorama stitching, hingga SLAM pada robotika.

Keypoint vs Descriptor

  1. Keypoint (Feature Point)
    Lokasi spesifik pada citra yang dianggap "menarik" — biasanya sudut (corner), blob, atau titik dengan tekstur khas. Dideteksi oleh algoritma feature detector (mis. Harris, FAST, DoG).
  2. Descriptor
    Vektor numerik yang merangkum penampakan area di sekitar keypoint. Descriptor yang baik harus invariant terhadap rotasi, skala, dan perubahan iluminasi sehingga keypoint yang sama tetap dapat dicocokkan meskipun citra ditransformasi.

1. HOG (Histogram of Oriented Gradients)

Diperkenalkan oleh Dalal & Triggs (2005) untuk pedestrian detection. HOG tidak menghasilkan descriptor pada keypoint sparse — sebaliknya, ia menghitung descriptor dense pada grid cell berukuran tetap di seluruh citra.

Cara kerja HOG:

  1. Hitung gradient magnitude dan arah pada setiap pixel.
  2. Bagi citra menjadi cell (mis. 8×8 pixel). Hitung histogram arah gradient (umumnya 9 bin: 0°–180°) untuk setiap cell.
  3. Kelompokkan cell menjadi block (mis. 2×2 cell = 16×16 pixel). Normalisasi histogram dalam block untuk robust terhadap perubahan pencahayaan.
  4. Concatenate semua block descriptor menjadi satu vektor besar (untuk window 64×128 menghasilkan 3.780 dimensi).

HOG biasanya dipasangkan dengan klasifikator SVM untuk deteksi objek dengan bentuk khas (pejalan kaki, kendaraan, wajah).

2. SIFT (Scale-Invariant Feature Transform)

Dipublikasikan oleh David Lowe (1999, 2004). SIFT adalah gold standard untuk feature matching karena invariant terhadap skala, rotasi, dan cukup robust terhadap perubahan iluminasi serta sudut pandang.

Tahapan SIFT:

  1. Scale-Space Extrema Detection
    Bangun pyramid citra pada berbagai skala (Gaussian + DoG). Cari ekstrema lokal pada DoG sebagai keypoint kandidat.
  2. Keypoint Localization
    Filter keypoint yang berkontras rendah atau terletak di tepi (edge response) — hanya pertahankan yang stabil.
  3. Orientation Assignment
    Berikan arah dominan pada setiap keypoint berdasarkan histogram gradient di sekitarnya. Ini yang membuat SIFT rotation-invariant.
  4. Descriptor Generation
    Bagi area 16×16 di sekitar keypoint menjadi 16 sub-region 4×4, masing-masing menghasilkan histogram 8 arah → descriptor 128 dimensi.
Lisensi & Alternatif

SIFT sebelumnya dipatenkan (kedaluwarsa 2020). SURF (Speeded-Up Robust Features) adalah versi lebih cepat yang juga sempat dipatenkan. Alternatif gratis sejak awal: ORB, BRISK, AKAZE. Pada OpenCV 4.4+, SIFT sudah tersedia di modul utama tanpa opencv-contrib.

3. ORB (Oriented FAST and Rotated BRIEF)

Dikembangkan oleh OpenCV Labs (2011) sebagai alternatif open-source SIFT/SURF. ORB sangat cepat dan cocok untuk aplikasi real-time (mobile, AR, robotika).

  1. Detector: FAST — mendeteksi sudut dengan membandingkan intensitas pixel pada lingkaran Bresenham radius 3.
  2. Descriptor: BRIEF — binary descriptor 256-bit, dihasilkan dari hasil perbandingan pasangan pixel tertentu. Sangat hemat memori dan cepat untuk matching (Hamming distance).
  3. Orientasi ditambahkan via intensity centroid untuk membuatnya rotation-invariant.

Perbandingan Singkat

Algoritma Tipe Dim. Kecepatan Use Case
HOG Dense 3.780 Sedang Deteksi pejalan kaki, klasifikasi bentuk
SIFT Sparse, float 128 Lambat Panorama stitching, recognition akurat
SURF Sparse, float 64 Cepat Alternatif SIFT lebih cepat
ORB Sparse, binary 256-bit Sangat cepat Real-time, mobile, SLAM, AR

Praktikum: Feature Detection & Matching

feature_matching.py 
import cv2
import numpy as np

img1 = cv2.imread('scene.jpg', cv2.IMREAD_GRAYSCALE)
img2 = cv2.imread('object.jpg', cv2.IMREAD_GRAYSCALE)

# === SIFT ===
sift = cv2.SIFT_create(nfeatures=500)
kp1, des1 = sift.detectAndCompute(img1, None)
kp2, des2 = sift.detectAndCompute(img2, None)
print(f"SIFT keypoints: {len(kp1)} & {len(kp2)}")

# Visualisasi keypoint
img_kp = cv2.drawKeypoints(
    img1, kp1, None,
    flags=cv2.DRAW_MATCHES_FLAGS_DRAW_RICH_KEYPOINTS
)

# === Matching dengan FLANN matcher (untuk SIFT/SURF) ===
FLANN_INDEX_KDTREE = 1
index_params = dict(algorithm=FLANN_INDEX_KDTREE, trees=5)
search_params = dict(checks=50)
flann = cv2.FlannBasedMatcher(index_params, search_params)
matches = flann.knnMatch(des1, des2, k=2)

# Ratio test (Lowe) — saring match yang ambigu
good = []
for m, n in matches:
    if m.distance < 0.7 * n.distance:
        good.append(m)
print(f"Good matches: {len(good)}")

# === ORB (alternative cepat) ===
orb = cv2.ORB_create(nfeatures=1000)
kp1o, des1o = orb.detectAndCompute(img1, None)
kp2o, des2o = orb.detectAndCompute(img2, None)

bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
matches_orb = sorted(bf.match(des1o, des2o), key=lambda x: x.distance)

# Gambar 30 match terbaik
img_match = cv2.drawMatches(
    img1, kp1o, img2, kp2o, matches_orb[:30], None,
    flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS
)

cv2.imshow('ORB Matches', img_match)
cv2.waitKey(0)

Praktikum: HOG untuk Pedestrian Detection

hog_pedestrian.py 
import cv2

img = cv2.imread('street.jpg')

# HOG descriptor + SVM pre-trained (pedestrian)
hog = cv2.HOGDescriptor()
hog.setSVMDetector(cv2.HOGDescriptor_getDefaultPeopleDetector())

# Multi-scale detection
rects, weights = hog.detectMultiScale(
    img,
    winStride=(8, 8),
    padding=(16, 16),
    scale=1.05
)

for (x, y, w, h), conf in zip(rects, weights):
    cv2.rectangle(img, (x, y), (x+w, y+h), (0, 255, 0), 2)
    cv2.putText(img, f"{conf[0]:.2f}", (x, y-5),
                cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0,255,0), 1)

cv2.imshow('HOG Pedestrian', img)
cv2.waitKey(0)
Era Deep Learning

Sejak 2012 (AlexNet), descriptor klasik seperti HOG dan SIFT mulai digeser oleh fitur yang dipelajari otomatis oleh CNN. Namun mereka tetap relevan untuk: aplikasi resource-constrained, dataset kecil tanpa training, geometric matching (panorama, SLAM), dan baseline pembanding penelitian.
