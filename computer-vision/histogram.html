Modul 6: Histogram & Thresholding

Estimasi: 70 Menit
Teori, Simulasi & Praktikum

Histogram citra menggambarkan distribusi frekuensi intensitas pixel — berapa banyak pixel yang memiliki nilai 0, 1, 2, ..., 255. Histogram adalah salah satu alat analisis paling sederhana namun powerful dalam Computer Vision. Dari histogram, kita bisa menentukan kontras citra, mendeteksi pencahayaan yang buruk, hingga melakukan segmentasi berbasis intensitas (thresholding).

Memahami Histogram

Untuk citra grayscale 8-bit, histogram adalah array berukuran 256 yang menyimpan jumlah pixel pada setiap level intensitas. Bentuk distribusi histogram menunjukkan karakteristik citra:

  1. Histogram condong ke kiri (dark)
    Mayoritas pixel berintensitas rendah — citra under-exposed (terlalu gelap).
  2. Histogram condong ke kanan (bright)
    Mayoritas pixel berintensitas tinggi — citra over-exposed (terlalu terang).
  3. Histogram sempit (low contrast)
    Rentang intensitas pendek — citra terlihat "datar" tanpa detail.
  4. Histogram merata (high contrast)
    Distribusi luas menyentuh kedua ujung — citra detail dan tajam.
  5. Histogram bimodal
    Dua puncak yang jelas — biasanya menandakan ada dua region utama (foreground vs background) → kandidat ideal untuk thresholding.

Histogram Equalization

Teknik untuk meratakan distribusi histogram sehingga seluruh rentang 0–255 termanfaatkan secara optimal. Hasilnya: citra dengan kontras lebih tinggi. Berguna untuk citra under/over-exposed.

CLAHE (Contrast Limited Adaptive Histogram Equalization) adalah varian yang lebih canggih: melakukan equalization secara lokal per blok kecil, dengan pembatasan kontras agar tidak memperkuat noise. CLAHE adalah pilihan default modern untuk enhancement.

Thresholding

Thresholding mengubah citra grayscale menjadi citra biner (hanya 0 dan 255) berdasarkan nilai ambang batas. Ini adalah teknik segmentasi paling sederhana.

  1. Binary Thresholding
    Pixel > T → 255, lainnya 0. T ditentukan manual.
  2. Otsu's Method
    Menghitung T secara otomatis dengan memaksimalkan between-class variance. Cocok untuk histogram bimodal.
  3. Adaptive Thresholding
    T dihitung berbeda untuk setiap region kecil — ideal untuk citra dengan pencahayaan tidak merata (mis. dokumen difoto).
  4. Triangle Method
    Cocok untuk histogram unimodal — menarik garis dari puncak histogram ke ujung dan memilih T yang menghasilkan jarak terjauh.

Praktikum: Histogram & Thresholding dengan OpenCV

histogram_threshold.py 
import cv2
import numpy as np
import matplotlib.pyplot as plt

img = cv2.imread('foto.jpg', cv2.IMREAD_GRAYSCALE)

# 1. Hitung histogram
hist = cv2.calcHist([img], [0], None, [256], [0, 256])

# 2. Histogram Equalization global
equ = cv2.equalizeHist(img)

# 3. CLAHE — adaptive equalization (recommended)
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
img_clahe = clahe.apply(img)

# 4. Binary thresholding manual
_, bin_th = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)

# 5. Otsu — threshold otomatis
otsu_t, otsu = cv2.threshold(img, 0, 255,
                              cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print(f"Otsu threshold: {otsu_t}")

# 6. Adaptive — untuk pencahayaan tidak merata
adapt = cv2.adaptiveThreshold(
    img, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 11, 2
)

# Visualisasi
fig, axes = plt.subplots(2, 3, figsize=(14, 9))
axes[0,0].imshow(img, cmap='gray');   axes[0,0].set_title('Original')
axes[0,1].imshow(equ, cmap='gray');   axes[0,1].set_title('HistEq')
axes[0,2].imshow(img_clahe, cmap='gray'); axes[0,2].set_title('CLAHE')
axes[1,0].imshow(bin_th, cmap='gray'); axes[1,0].set_title('Binary 127')
axes[1,1].imshow(otsu, cmap='gray');   axes[1,1].set_title(f'Otsu T={int(otsu_t)}')
axes[1,2].imshow(adapt, cmap='gray');  axes[1,2].set_title('Adaptive')
for ax in axes.flat: ax.axis('off')
plt.tight_layout(); plt.show()
Kapan Pakai Apa?

Otsu — default untuk citra dengan histogram bimodal (objek vs background terang). Adaptive — ketika ada bayangan/pencahayaan tidak merata (mis. OCR dokumen). Manual — ketika threshold sudah diketahui dari domain knowledge. CLAHE — sebagai pre-processing sebelum threshold pada citra medis/satelit.
