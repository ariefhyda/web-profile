Modul 11: Final Project Computer Vision

Durasi: 3–4 Minggu
Individu / Tim 2–3 Orang

Final project adalah ujian sintesis dari seluruh materi Computer Vision yang telah dipelajari. Kamu akan membangun sebuah aplikasi end-to-end — dari pengumpulan data, training/fine-tuning model, evaluasi kuantitatif, hingga deployment dalam bentuk demo interaktif.

Tujuan Pembelajaran

  1. Mengidentifikasi masalah dunia nyata yang dapat diselesaikan dengan Computer Vision dan merumuskannya sebagai task CV (klasifikasi, deteksi, atau segmentasi).
  2. Mengumpulkan dan menyiapkan dataset — data augmentation, anotasi, train/val/test split.
  3. Memilih dan menerapkan model yang tepat — baseline klasik vs deep learning, transfer learning vs train from scratch.
  4. Mengevaluasi performa secara kuantitatif — metrik yang sesuai task, error analysis, ablation study.
  5. Mendokumentasikan dan mempresentasikan hasil dengan jelas: laporan, slide, dan demo aplikasi.

Pilihan Topik (Pick One)

Detection

PPE Compliance Detector

Deteksi penggunaan helm, rompi, dan sepatu safety di area konstruksi/pabrik. Latih YOLOv8 pada dataset kustom (200+ gambar). Output: bbox + status compliance per orang.

Classification

Klasifikasi Penyakit Tanaman

Fine-tune CNN (ResNet/EfficientNet) untuk klasifikasi penyakit pada daun tanaman (mis. PlantVillage dataset). Sertakan Grad-CAM untuk interpretasi.

Segmentation

Segmentasi Citra Medis

U-Net untuk segmentasi nuclei, tumor, atau pembuluh darah pada citra histopatologi/CT scan. Evaluasi dengan Dice coefficient.

OCR

License Plate Recognition

Pipeline 2 tahap: deteksi plat (YOLO) + pengenalan karakter (Tesseract / EasyOCR / CRNN). Uji pada video CCTV gerbang.

Tracking

People Counter

YOLO + tracking (ByteTrack/DeepSORT) untuk menghitung orang yang masuk/keluar pada garis virtual di video. Cocok untuk retail analytics.

Custom

Topik Bebas

Punya ide sendiri? Ajukan proposal singkat (1 halaman) berisi: latar belakang, data, model, metrik, dan deliverable. Wajib disetujui dosen sebelum mulai.

Deliverables

  1. Repository GitHub
    Source code lengkap, dengan README jelas (instalasi, cara menjalankan, struktur folder), requirements.txt, dan minimal satu notebook reproducible.
  2. Dataset
    Link dataset (Drive/Roboflow/Kaggle) atau script untuk download. Jika menggunakan data privat, sertakan sample.
  3. Model Weights
    File model terlatih (.pt / .h5 / .onnx) di-host di GitHub Releases atau Drive.
  4. Demo Aplikasi
    Salah satu: (a) Streamlit/Gradio app, (b) FastAPI endpoint, (c) script CLI dengan input video/gambar yang menghasilkan output ter-annotated.
  5. Laporan Teknis (PDF, 8–12 halaman)
    Format paper: Abstract, Introduction, Related Work, Method, Experiment, Result & Discussion, Conclusion, Reference.
  6. Slide Presentasi (10–15 slide)
    Untuk demo day. Sertakan video demo durasi 1–3 menit.

Tips Sukses

  1. Mulai dari baseline sederhana
    Jangan langsung pakai model SOTA. Baseline (mis. YOLOv8n pretrained tanpa fine-tune) menjadi tolok ukur apakah model kustommu benar-benar lebih baik.
  2. Iterate cepat, scope kecil
    Lebih baik proyek sederhana yang selesai & bekerja, daripada proyek ambisius yang setengah jadi.
  3. Versioning eksperimen
    Gunakan W&B, MLflow, atau minimal spreadsheet untuk catat: konfigurasi, data, metrik. Tanpa ini kamu akan lupa kombinasi mana yang terbaik.
  4. Visualisasi hasil salah
    Lihat 20–30 contoh false-positive dan false-negative. Pola yang muncul akan mengarahkan perbaikan (data tambahan? augmentation berbeda? class merging?).
  5. Reproducibility
    Set random seed, freeze versi library di requirements.txt, dokumentasikan langkah persis. Penguji harus bisa menjalankan kodemu tanpa bertanya.
