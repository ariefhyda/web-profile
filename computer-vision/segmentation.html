Modul 10: Image Segmentation

Estimasi: 80 Menit
Teori & Praktikum

Image segmentation adalah task Computer Vision yang memberi label kelas pada setiap pixel citra — bukan hanya bounding box. Hasilnya adalah peta segmentasi yang menjelaskan dengan presisi pixel-level: "pixel ini bagian dari mobil", "pixel ini bagian dari jalan", dan seterusnya. Sangat penting untuk aplikasi seperti citra medis, autonomous driving, dan editing foto.

Tiga Jenis Segmentasi

  1. Semantic Segmentation
    Setiap pixel diberi label kelas, tapi tidak membedakan antar instance. Dua mobil yang bersebelahan akan diwarnai sama. Output: tensor H×W dengan nilai kelas.
  2. Instance Segmentation
    Setiap objek dipisahkan sebagai instance berbeda meski kelasnya sama. Mobil pertama dan mobil kedua mendapat warna berbeda. Cocok untuk counting dan tracking.
  3. Panoptic Segmentation
    Gabungan keduanya: semua pixel mendapat label, instance "things" (mobil, orang) dipisahkan, sedangkan "stuff" (langit, jalan) diperlakukan sebagai semantic. Output paling lengkap untuk scene understanding.

Pendekatan Klasik (Non-Deep-Learning)

Sebelum era deep learning, segmentasi menggunakan teknik berbasis intensitas, region, atau graph:

  1. Thresholding — pisahkan foreground/background berdasarkan intensitas (Otsu). Sederhana tapi terbatas.
  2. Watershed — analogi "membanjiri" cekungan gradient citra; baik untuk objek yang saling menempel.
  3. GrabCut — segmentasi interaktif berbasis Graph Cut, user memberi marker foreground/background.
  4. Mean-Shift / K-Means — clustering warna pixel untuk segmentasi region.

U-Net — Arsitektur Encoder-Decoder

Diperkenalkan oleh Ronneberger et al. (2015) untuk segmentasi citra biomedis. U-Net menjadi baseline wajib untuk semantic segmentation karena kesederhanaan dan efektivitasnya bahkan dengan dataset kecil.

Arsitekturnya berbentuk huruf U:

  1. Encoder (Contracting Path)
    Serangkaian Conv + MaxPool yang mengecilkan resolusi spasial dan memperdalam channel. Tujuannya: ekstraksi fitur semantik tingkat tinggi.
  2. Bottleneck
    Lapisan terdalam dengan fitur paling abstrak.
  3. Decoder (Expanding Path)
    Serangkaian Up-conv (transposed convolution) yang mengembalikan resolusi spasial.
  4. Skip Connections
    Inilah kunci U-Net — fitur dari encoder di-concat ke decoder pada resolusi yang sama. Membantu decoder merekonstruksi detail spasial yang hilang akibat pooling.
  5. Output
    Layer 1×1 Conv yang menghasilkan probabilitas per pixel untuk setiap kelas.

Mask R-CNN — Instance Segmentation

Dikembangkan He et al. (2017) di Facebook AI Research. Mask R-CNN adalah ekstensi dari Faster R-CNN dengan cabang ketiga yang memprediksi mask biner untuk setiap region proposal.

  1. Backbone — ResNet/ResNeXt + FPN untuk ekstraksi fitur multi-scale.
  2. RPN (Region Proposal Network) — mengusulkan kandidat bounding box.
  3. RoIAlign — perbaikan dari RoIPool, menggunakan interpolasi bilinear sehingga lebih presisi (penting untuk mask).
  4. Tiga Head Output — classification, bbox regression, dan mask (kecil, 28×28) per RoI yang kemudian di-resize ke ukuran bbox.

DeepLab — Atrous Convolution

Keluarga model dari Google (DeepLabv1 sampai v3+). Inovasi utamanya adalah atrous (dilated) convolution — konvolusi dengan "lubang" di antara elemen kernel, sehingga receptive field membesar tanpa kehilangan resolusi spasial. ASPP (Atrous Spatial Pyramid Pooling) menggabungkan beberapa dilation rate untuk menangkap konteks multi-scale.

SAM — Segment Anything Model

Dirilis Meta AI (2023). SAM adalah foundation model untuk segmentasi yang dilatih pada 1+ miliar mask. Model dapat melakukan segmentasi zero-shot untuk objek apa pun — cukup berikan prompt (titik, box, atau teks) dan SAM menghasilkan mask. Mengubah lanskap segmentasi: dari "training custom model" menjadi "prompt model siap pakai".

Metrik Evaluasi

  1. Pixel Accuracy
    Persentase pixel dengan prediksi benar. Mudah, tapi bias jika kelas tidak seimbang (background dominan).
  2. IoU per Kelas (Jaccard Index)
    IoU dihitung antara mask prediksi dan ground truth untuk setiap kelas.
  3. mIoU (mean IoU)
    Rata-rata IoU semua kelas — metrik standar (mis. Cityscapes, Pascal VOC).
  4. Dice Coefficient
    2 × |A ∩ B| / (|A| + |B|). Banyak dipakai di citra medis karena lebih sensitif pada objek kecil.

Praktikum 1: Watershed Segmentation

watershed_demo.py 
import cv2
import numpy as np

img = cv2.imread('coins.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 1. Threshold Otsu
_, thresh = cv2.threshold(gray, 0, 255,
                          cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)

# 2. Hilangkan noise + sure background
kernel = np.ones((3,3), np.uint8)
opening = cv2.morphologyEx(thresh, cv2.MORPH_OPEN, kernel, iterations=2)
sure_bg = cv2.dilate(opening, kernel, iterations=3)

# 3. Sure foreground via distance transform
dist = cv2.distanceTransform(opening, cv2.DIST_L2, 5)
_, sure_fg = cv2.threshold(dist, 0.7*dist.max(), 255, 0)
sure_fg = np.uint8(sure_fg)

# 4. Unknown region + marker labeling
unknown = cv2.subtract(sure_bg, sure_fg)
_, markers = cv2.connectedComponents(sure_fg)
markers = markers + 1
markers[unknown == 255] = 0

# 5. Apply watershed
markers = cv2.watershed(img, markers)
img[markers == -1] = [0, 0, 255]  # garis pemisah merah

cv2.imshow('Segmented', img)
cv2.waitKey(0)

Praktikum 2: U-Net dengan PyTorch (Sketch)

unet_minimal.py 
import torch
import torch.nn as nn

def conv_block(in_c, out_c):
    return nn.Sequential(
        nn.Conv2d(in_c, out_c, 3, padding=1), nn.ReLU(inplace=True),
        nn.Conv2d(out_c, out_c, 3, padding=1), nn.ReLU(inplace=True),
    )

class UNet(nn.Module):
    def __init__(self, n_classes=1):
        super().__init__()
        self.enc1 = conv_block(3, 64)
        self.enc2 = conv_block(64, 128)
        self.enc3 = conv_block(128, 256)
        self.bottleneck = conv_block(256, 512)
        self.up3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = conv_block(512, 256)
        self.up2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = conv_block(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = conv_block(128, 64)
        self.out  = nn.Conv2d(64, n_classes, 1)
        self.pool = nn.MaxPool2d(2)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        b  = self.bottleneck(self.pool(e3))
        d3 = self.dec3(torch.cat([self.up3(b),  e3], dim=1))
        d2 = self.dec2(torch.cat([self.up2(d3), e2], dim=1))
        d1 = self.dec1(torch.cat([self.up1(d2), e1], dim=1))
        return self.out(d1)

# Loss umum: BCEWithLogitsLoss (binary) atau CrossEntropyLoss (multi-class)
# Tambahan: Dice Loss untuk class-imbalance pada citra medis

Praktikum 3: YOLO-Seg (Instance Segmentation)

yolo_seg.py 
from ultralytics import YOLO
import cv2

# Model segmentation (suffix -seg)
model = YOLO('yolov8n-seg.pt')

results = model('scene.jpg')

for r in results:
    if r.masks is not None:
        for mask, cls in zip(r.masks.data, r.boxes.cls):
            label = model.names[int(cls)]
            print(f"{label}: mask area = {mask.sum().item():.0f} px")

    annotated = r.plot()
    cv2.imwrite('segmented.jpg', annotated)
Loss Function untuk Segmentasi

Untuk dataset dengan class-imbalance (mis. tumor <1% pixel), gunakan kombinasi BCE + Dice Loss atau Focal Loss. Cross-entropy biasa cenderung mengabaikan kelas minoritas dan terlihat "akurat" karena mayoritas background ter-prediksi benar.
