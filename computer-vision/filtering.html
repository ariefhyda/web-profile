Modul 4: Filtering & Konvolusi

Estimasi: 80 Menit
Teori, Simulasi & Praktikum

Filtering (penapisan) adalah teknik fundamental dalam pemrosesan citra yang dilakukan dengan operasi konvolusi (convolution). Filter digunakan untuk berbagai keperluan: menghilangkan noise, mempertajam detail, mendeteksi tepi, hingga menciptakan efek artistik.

Apa itu Konvolusi?

Konvolusi adalah operasi matematis di mana sebuah kernel (matriks kecil, biasanya 3×3 atau 5×5) digeser ke seluruh pixel citra. Pada setiap posisi, nilai pixel output adalah jumlah dari hasil perkalian elemen kernel dengan pixel tetangga yang dilewatinya.

Jenis-Jenis Filter

1. Smoothing / Blurring Filter

Bertujuan menghaluskan citra dengan mengurangi variasi intensitas yang tajam. Berguna untuk noise reduction dan sebagai pre-processing untuk algoritma yang sensitif terhadap noise.

  1. Box Filter (Mean Filter)
    Semua elemen kernel bernilai sama. Sederhana namun menghasilkan blur yang "kotak-kotak" — semua tetangga diperlakukan sama bobotnya.
  2. Gaussian Filter
    Bobot tetangga mengikuti distribusi Gaussian — pixel pusat punya bobot terbesar, tetangga jauh bobot kecil. Hasil blur lebih natural dan smooth. Parameter penting: sigma (lebar distribusi).
  3. Median Filter
    Bukan konvolusi linier — mengambil median dari nilai pixel di window. Sangat efektif menghilangkan salt-and-pepper noise tanpa membuat tepi menjadi blur.
  4. Bilateral Filter
    Mempertimbangkan kedekatan spasial DAN kemiripan intensitas. Hasil: noise berkurang tapi tepi tetap tajam (edge-preserving smoothing).

2. Sharpening Filter

Memperkuat detail dan tepi citra. Konsep dasarnya: citra asli + (citra asli - blurred) = citra dengan detail dipertajam (teknik unsharp masking).

3. Derivative / Edge Filter

Menghitung perubahan intensitas (gradient) — output tinggi pada lokasi tepi. Contoh: Sobel, Prewitt, Laplacian. Dibahas detail di modul Edge Detection.

Praktikum: Filtering dengan OpenCV

filtering_demo.py 
import cv2
import numpy as np

img = cv2.imread('foto.jpg')

# 1. Box Blur
box_blur = cv2.blur(img, (5, 5))

# 2. Gaussian Blur — yang paling sering dipakai
gaussian = cv2.GaussianBlur(img, (7, 7), sigmaX=1.5)

# 3. Median Blur — bagus untuk salt-and-pepper noise
median = cv2.medianBlur(img, 5)

# 4. Bilateral — edge preserving
bilateral = cv2.bilateralFilter(img, d=9,
                              sigmaColor=75,
                              sigmaSpace=75)

# 5. Custom kernel (sharpening)
kernel_sharpen = np.array([[ 0, -1,  0],
                           [-1,  5, -1],
                           [ 0, -1,  0]])
sharpened = cv2.filter2D(img, -1, kernel_sharpen)

# 6. Unsharp masking (lebih halus dari sharpen kernel)
blurred = cv2.GaussianBlur(img, (5,5), 1.0)
unsharp = cv2.addWeighted(img, 1.5, blurred, -0.5, 0)
Padding & Border Handling

Ketika kernel diterapkan pada pixel di tepi citra, ada tetangga yang berada "di luar" citra. OpenCV menangani ini dengan padding — default BORDER_REFLECT_101. Pilihan lain: BORDER_CONSTANT (isi dengan nilai tetap), BORDER_REPLICATE (duplikasi pixel terluar), atau BORDER_WRAP.
