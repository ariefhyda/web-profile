Modul 13: Membangun REST API

Estimasi: 55 Menit
Teori & Praktikum

Selain sebagai aplikasi web full-stack, Laravel juga sangat baik sebagai backend API. API ini bisa di-konsumsi oleh aplikasi Mobile (Android/iOS), frontend SPA (React/Vue), atau aplikasi pihak ketiga. Modul ini fokus pada pola RESTful — standar industri untuk API.

📡
Analogi: Pelayan Restoran

API = pelayan yang menjembatani Anda (client) dengan dapur (server/database). Anda kirim pesanan (request), pelayan bawa balik makanan (response). Tidak ada interaksi langsung dengan dapur. REST = aturan komunikasi: pakai "bahasa" HTTP (GET, POST, PUT, DELETE) untuk operasi CRUD.

REST: Aturan Main API yang Baik

  1. Stateless
    Setiap request berdiri sendiri — server tidak menyimpan "konteks" antar request. Tiap request bawa info lengkap (termasuk auth token).
  2. Resource-based
    URL menggambarkan resource (kata benda), bukan aksi. /users bukan /getAllUsers.
  3. HTTP Methods semantik
    GET=baca, POST=buat, PUT=update penuh, PATCH=update sebagian, DELETE=hapus.
  4. Standard response (JSON)
    Format response konsisten — JSON dengan status code HTTP yang tepat.

HTTP Status Code Cheatsheet

Status code bukan dekorasi — ia memberi tahu client apa yang terjadi. Klien yang baik (mobile app, frontend) akan merespons berbeda untuk 200 vs 404 vs 500.

200
OK
Request sukses (GET, PUT, DELETE).
201
Created
Resource baru berhasil dibuat (POST).
204
No Content
Sukses, tapi tidak ada body. (DELETE)
301
Moved
Resource pindah permanen.
400
Bad Request
Request malformed — sintaks salah.
401
Unauthorized
Belum login / token tidak ada.
403
Forbidden
Login OK, tapi tidak punya izin.
404
Not Found
Resource tidak ditemukan.
422
Unprocessable
Validasi gagal (Laravel default).
429
Too Many
Rate limit terlampaui (throttle).
500
Server Error
Error tak terduga di server.
503
Unavailable
Maintenance / overload.

Routing API di Laravel

Semua route API dideklarasikan di routes/api.php. URL otomatis di-prefix /api.

Laravel 11+: install:api

Mulai Laravel 11, file api.php tidak tersedia secara default. Aktifkan dengan: php artisan install:api. Perintah ini juga akan menginstal Laravel Sanctum untuk token authentication.

routes/api.php 
use App\Http\Controllers\Api\ProductController;

// URL otomatis dapat prefix /api/
Route::get('/products', [ProductController::class, 'index']);
Route::post('/products', [ProductController::class, 'store']);
Route::get('/products/{product}', [ProductController::class, 'show']);

// apiResource → 5 route CRUD (tanpa create & edit, karena tidak butuh form view)
Route::apiResource('products', ProductController::class);

// Group dengan auth Sanctum
Route::middleware('auth:sanctum')->group(function () {
    Route::post('/products', [ProductController::class, 'store']);
    Route::delete('/products/{product}', [ProductController::class, 'destroy']);
});

Controller API — Return JSON

Di Controller web, biasanya return view. Di API, return array/collection — Laravel otomatis serialize ke JSON dengan content-type yang benar.

app/Http/Controllers/Api/ProductController.php 
class ProductController extends Controller
{
    // GET /api/products — list semua
    public function index()
    {
        return Product::all();
        // → 200 OK + JSON array
    }

    // GET /api/products/{product} — detail
    public function show(Product $product)
    {
        return $product;
        // → 200 OK + JSON object
        // → 404 Not Found jika tidak ada (auto via Route Model Binding)
    }

    // POST /api/products — create baru
    public function store(Request $request)
    {
        $validated = $request->validate([
            'name'  => 'required|string|max:255',
            'price' => 'required|integer|min:0',
        ]);
        // Validasi gagal → otomatis 422 + JSON errors

        $product = Product::create($validated);

        return response()->json([
            'message' => 'Produk berhasil dibuat',
            'data'    => $product,
        ], 201); // 201 Created
    }

    // PUT /api/products/{product}
    public function update(Request $request, Product $product)
    {
        $product->update($request->validated());
        return $product;
    }

    // DELETE /api/products/{product}
    public function destroy(Product $product)
    {
        $product->delete();
        return response()->noContent(); // 204 No Content
    }
}

API Resources — Format Output Konsisten

Mengembalikan Model langsung mengekspos semua kolom (termasuk yang sensitif!). Pakai Eloquent API Resources untuk transformasi data sebelum dikirim ke client.

Terminal 
php artisan make:resource ProductResource
app/Http/Resources/ProductResource.php 
public function toArray(Request $request): array
{
    return [
        'id'              => $this->id,
        'name'            => $this->name,
        'price'           => $this->price,
        'price_formatted' => 'Rp ' . number_format($this->price, 0, ',', '.'),
        'image_url'       => $this->image_path ? asset($this->image_path) : null,
        'created_at'      => $this->created_at->format('Y-m-d H:i'),
        // Conditional: include hanya jika user ini owner
        'cost_price'      => $this->when($request->user()?->id === $this->user_id, $this->cost_price),
        // Include relasi
        'category'        => CategoryResource::make($this->whenLoaded('category')),
    ];
}
ProductController.php (pakai Resource) 
public function index()
{
    // Banyak: pakai collection()
    return ProductResource::collection(
        Product::with('category')->paginate(15)
    );
}

public function show(Product $product)
{
    // Satu: pakai make()
    return ProductResource::make($product->load('category'));
}

Authentication API: Laravel Sanctum

Untuk API yang dipakai mobile/SPA, butuh autentikasi via token (bukan session cookie). Sanctum adalah package resmi yang sederhana dan ringan.

Setup Sanctum 
# Install (sudah include di install:api Laravel 11+)
composer require laravel/sanctum
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"
php artisan migrate

# Tambahkan trait di User model
use Laravel\Sanctum\HasApiTokens;
class User extends Authenticatable
{
    use HasApiTokens, HasFactory, Notifiable;
}
routes/api.php — login endpoint 
Route::post('/login', function (Request $request) {
    $credentials = $request->validate([
        'email'    => 'required|email',
        'password' => 'required',
    ]);

    if (!Auth::attempt($credentials)) {
        return response()->json(['message' => 'Email atau password salah.'], 401);
    }

    $user  = Auth::user();
    $token = $user->createToken('api-token')->plainTextToken;

    return response()->json([
        'token' => $token,
        'user'  => $user,
    ]);
});

// Route protected — wajib kirim header: Authorization: Bearer <token>
Route::middleware('auth:sanctum')->group(function () {
    Route::get('/me', fn (Request $r) => $r->user());
    Route::post('/logout', fn (Request $r) => $r->user()->currentAccessToken()->delete());
});

Testing API dengan Postman / Thunder Client

Tools yang Wajib Dimiliki

Untuk test API tanpa harus build frontend dulu, pakai Postman, Insomnia, atau Thunder Client (ekstensi VS Code). Anda bisa kirim request lengkap (method, header, body) dan lihat response JSON. Wajib untuk debug API.

contoh: kirim request lewat cURL 
# GET — list semua produk
curl http://localhost:8000/api/products

# POST — create produk (tanpa auth)
curl -X POST http://localhost:8000/api/products \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"name":"Laptop","price":15000000}'

# POST — pakai token Sanctum
curl -X POST http://localhost:8000/api/products \
  -H "Authorization: Bearer 1|abcdef123..." \
  -H "Content-Type: application/json" \
  -d '{"name":"Laptop","price":15000000}'
