Modul 12: Authentication

Estimasi: 50 Menit
Teori & Praktikum

Membangun sistem login dari nol butuh berhari-hari: hashing password, session management, "Remember Me", reset password, verifikasi email, proteksi brute-force. Untungnya Laravel menyediakan semua ini out-of-the-box lewat Starter Kits.

🔐
Analogi: Kunci & Kartu Akses

Bayangkan gedung kantor. Authentication = "siapa kamu?" — tunjukkan kartu identitas (login). Authorization = "boleh masuk ruangan mana?" — tergantung level kartu Anda (admin / staff / tamu). Laravel mengelola keduanya secara terpisah.

Authentication vs Authorization

Authentication (AuthN) = verifikasi identitas — apakah email & password benar? Authorization (AuthZ) = pengecekan izin — apakah user ini boleh edit post milik orang lain? AuthN selalu dulu, baru AuthZ.

Starter Kit: Laravel Breeze

Daripada bangun manual, pakai Breeze — starter kit resmi yang menyediakan: login, register, reset password, verifikasi email, ubah profil. Cocok untuk pemula.

Terminal 
# 1. Install package Breeze
composer require laravel/breeze --dev

# 2. Install scaffolding (pilih stack: blade, react, vue, atau api)
php artisan breeze:install blade

# 3. Migration tabel users
php artisan migrate

# 4. Compile asset frontend (Tailwind + Vite)
npm install
npm run dev
Hasil Otomatis

Setelah breeze:install, Anda dapat: /login, /register, /forgot-password, /reset-password, /profile, /dashboard, plus middleware auth dan guest siap pakai. Total: ~15 menit, hemat 3 hari coding.

Facade Auth — Akses User di Controller

PHP 
use Illuminate\Support\Facades\Auth;

// Cek apakah user sudah login
if (Auth::check()) { /* logged in */ }

// Helper alternatif (sama saja)
if (auth()->check()) { ... }

// Ambil user yang login
$user = Auth::user();
echo $user->name;
echo $user->email;

// Hanya ID-nya saja (lebih ringan)
$id = Auth::id();

// Login manual (mis. setelah registrasi custom)
Auth::login($userInstance);

// Login dengan kredensial (mis. custom login)
if (Auth::attempt(['email' => $email, 'password' => $pwd])) {
    $request->session()->regenerate(); // session fixation protection
    return redirect()->intended('/dashboard');
}

// Logout
Auth::logout();

Proteksi Route dengan Middleware auth

routes/web.php 
// Satu route
Route::get('/dashboard', function () {
    return view('dashboard');
})->middleware('auth');

// Group untuk banyak route (lebih DRY)
Route::middleware('auth')->group(function () {
    Route::get('/dashboard', [DashboardController::class, 'index']);
    Route::resource('posts', PostController::class);
    Route::get('/profile', [ProfileController::class, 'show']);
});

// Route khusus tamu (mis. login & register, tidak boleh diakses user login)
Route::middleware('guest')->group(function () {
    Route::get('/login', [LoginController::class, 'show']);
    Route::post('/login', [LoginController::class, 'login']);
});

Authorization — Gate & Policy

Authentication menjawab "siapa kamu?". Authorization menjawab "apakah kamu boleh?". Pakai Gate (sederhana, closure) atau Policy (terstruktur, per-Model).

Gate (Sederhana)

app/Providers/AppServiceProvider.php 
use Illuminate\Support\Facades\Gate;

public function boot(): void
{
    // Definisi: siapa yang boleh "update-post"?
    Gate::define('update-post', function (User $user, Post $post) {
        return $user->id === $post->user_id;
    });
}
PostController.php 
public function update(Request $request, Post $post)
{
    // Cek izin — kalau gagal, throw 403
    Gate::authorize('update-post', $post);

    // ... lanjut update
}

Policy (Terstruktur — Direkomendasikan)

app/Policies/PostPolicy.php 
# Generate: php artisan make:policy PostPolicy --model=Post

class PostPolicy
{
    public function update(User $user, Post $post): bool
    {
        return $user->id === $post->user_id;
    }

    public function delete(User $user, Post $post): bool
    {
        return $user->id === $post->user_id
            || $user->role === 'admin';
    }
}

// Pemakaian di controller:
$this->authorize('update', $post);

// Di Blade:
@can('update', $post)
    <a href="{{ route('posts.edit', $post) }}">Edit</a>
@endcan

Login Custom (Tanpa Breeze)

AuthController.php 
public function login(Request $request)
{
    $credentials = $request->validate([
        'email'    => 'required|email',
        'password' => 'required',
    ]);

    if (Auth::attempt($credentials, $request->boolean('remember'))) {
        $request->session()->regenerate(); // keamanan session fixation
        return redirect()->intended('/dashboard');
    }

    return back()->withErrors([
        'email' => 'Kredensial tidak cocok dengan data kami.',
    ])->onlyInput('email');
}

public function logout(Request $request)
{
    Auth::logout();
    $request->session()->invalidate();
    $request->session()->regenerateToken();
    return redirect('/');
}
