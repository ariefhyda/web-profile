Game: OOP Quest — Kuasai OOP Dart Sambil Bermain

Estimasi: 30–45 Menit
8 Level • 25 Tantangan

Setelah mempelajari teori di Modul 4: Function & OOP, saatnya menguji pemahaman Anda. Di game ini Anda berperan sebagai developer junior yang ditugaskan membangun aplikasi KampusKu. Setiap konsep OOP yang Anda kuasai akan membuka satu fitur baru pada aplikasi di layar ponsel.

Cara Bermain

Setiap level dibuka dengan briefing singkat, lalu diikuti tantangan: Lengkapi Kode (klik kotak kosong, lalu klik potongan kode yang tepat), Tebak Output, dan Sortir Kilat. Jawaban benar pada percobaan pertama bernilai 100 XP; percobaan berikutnya bernilai lebih kecil. Level bisa diulang kapan saja untuk memperbaiki bintang, dan progres tersimpan otomatis di browser ini.

Aturan Fair Play

Kerjakan tantangan dengan kemampuan sendiri. Selama tantangan berlangsung, game mengawasi tiga hal: menyalin soal (copy/cut), tangkapan layar, dan meninggalkan halaman (pindah tab atau membuka aplikasi lain, misalnya untuk bertanya ke AI). Setiap pelanggaran mengurangi 25 XP dari total Anda dan tercatat permanen pada papan skor. Khusus meninggalkan halaman, satu kali pertama hanya diberi peringatan. Membaca briefing dan penjelasan jawaban tidak diawasi.

Peta Konsep: dari OOP ke Flutter

Gunakan daftar berikut sebagai rangkuman setelah menamatkan game. Setiap konsep OOP di Dart punya padanan langsung yang Anda tulis setiap hari saat membuat aplikasi Flutter.

  1. Class & Object — setiap widget adalah object: Text('Halo') membuat object dari class Text.
  2. Constructor — named parameter (Container(width: 100)), const, dan factory fromJson untuk data API.
  3. Encapsulation — awalan _ pada _HomePageState dan variabel state seperti _counter.
  4. Inheritance — extends StatelessWidget / extends StatefulWidget pada setiap halaman.
  5. Polymorphism — @override Widget build(), dan List<Widget> yang berisi beragam jenis widget.
  6. Abstraction & Interface — pola repository: abstract class sebagai kontrak, implements untuk versi API dan versi tes.
  7. Mixin — with SingleTickerProviderStateMixin saat membuat animasi.
  8. static, final, copyWith, enum, generics — Colors.blue, field widget yang final, TextStyle.copyWith(), dan State<T>.
