Modul 2.2: Audio Project

Estimasi: 45 Menit
Praktikum

Audio Project memungkinkan Anda melatih model untuk mengenali suara pendek (biasanya 1 detik). Teachable Machine mengubah suara menjadi Spectrogram (representasi visual suara) agar bisa diproses oleh arsitektur model gambar.

Langkah Praktikum 1: Membuat Model Suara di Teachable Machine

Pembuatan model suara memiliki tantangan yang berbeda dengan gambar. Dalam project audio, kita berurusan dengan durasi rekaman dan noise sekitar. Mari kita buat model yang bisa membedakan "Suara Tepuk Tangan", "Suara Bersiul", dan Keadaan Hening.

Step 1: Perekaman Wajib (Background Noise)

Buka Teachable Machine lalu pilih Audio Project. Anda akan melihat hal pertama yang WAJIB dilakukan adalah mengisi kelas Background Noise.

  • Mengapa wajib? Mikrofon ponsel dan laptop selalu menangkap suara dengungan ruangan (AC, kipas, angin, atau jalanan). Model harus tahu seperti apa "suara kosong" di ruangan Anda, agar tidak salah mengira noise tersebut sebagai sebuah perintah.
  • Cara rekam: Klik tombol Mic pada kelas Background Noise. Klik tombol Record 20 Seconds dan diamlah. Biarkan mikrofon merekam suara hening ruangan Anda selama 20 detik penuh. Sistem kemudian akan otomatis memecah rekaman tersebut menjadi potongan-potongan sampel kecil berdurasi 1 detik.

Step 2: Mendefinisikan Kelas Perintah (Dataset Gathering)

Setelah Background Noise terpenuhi, kita siap membuat kelas untuk suara perintah yang ingin dikenali.

Ubah Nama Kelas

Ganti nama Class 2 menjadi "Tepuk". Kemudian, klik Add a class untuk menambahkan kelas baru dan beri nama "Siul".

Rekam Sampel

Klik Mic di kelas "Tepuk". Rekam suara tepukan tangan Anda berulang-ulang hingga terkumpul minimal 20-30 detik total rekaman.

Konsistensi Jarak

Lakukan hal yang sama untuk "Siul". Usahakan menjaga jarak konsisten antara sumber suara dan mikrofon agar data lebih akurat.

Tips Praktikum

Saat merekam suara tepuk tangan atau siulan, pastikan ada sedikit jeda di antara bunyinya. Teachable Machine akan otomatis menangkap dan mengekstrak audio Anda ke dalam potongan 1 detik. Jika suara terlalu rapat dan terpotong di tengah, kualitas dataset untuk dipelajari model akan menurun.

Step 3: Training & Rahasia "Spectrogram"

Setelah data terkumpul, klik tombol Train Model. Proses ini memakan waktu beberapa saat. Sambil menunggu, tahukah Anda apa yang sebenarnya dipelajari oleh model?

Teachable Machine tidak benar-benar mempelajari "suara" dalam bentuk gelombangnya langsung. Ia mengubah gelombang audio mentah Anda menjadi gambar 2D yang disebut Spectrogram (gambar visual yang merepresentasikan frekuensi dan amplitudo suara dari waktu ke waktu). Model Machine Learning kemudian dilatih untuk mengenali pola visual dari gambar Spectrogram tersebut. Inilah mengapa arsitektur model AI untuk audio seringkali menggunakan teknologi yang sama dengan pengenalan gambar (CNN / Convolutional Neural Network)!

Step 4: Uji Coba & Export Model

Setelah proses training selesai, area Preview di sebelah kanan akan aktif. Cobalah bertepuk tangan, bersiul, atau sekadar diam. Bar persentase harusnya bergerak dan mendeteksi suara yang ia dengar secara real-time.

Jika pendeteksinya sudah akurat dan memuaskan, saatnya membawa model ini ke project Flutter Anda:

  • Klik tombol Export Model.
  • Pilih tab TensorFlow Lite (format standar untuk menjalankan model AI di perangkat mobile).
  • Pilih model Quantized. Sangat disarankan memilih tipe ini karena model akan dikompresi sehingga ukuran filenya jauh lebih kecil dan sangat ringan saat dijalankan pada RAM HP, tanpa mengurangi akurasi secara signifikan.
  • Terakhir, klik Download my model. Anda akan mendapatkan file berformat .tflite dan labels.txt yang dikemas dalam sebuah file ZIP.

Langkah Praktikum 2: Implementasi di Flutter dengan GetX

Kita akan membuat project baru dengan struktur sederhana — flat, tanpa folder modules/bindings/routes seperti pola GetCLI. Hanya 5 file di folder lib/: main.dart, home_page.dart, dan dua pasang controller+page untuk upload dan realtime.

Step 1: Buat Project & Dependencies

Terminal 
flutter create klasifikasi_audio
cd klasifikasi_audio
flutter pub add get tflite_flutter permission_handler record file_picker

Buat folder assets/ml/ dan salin file soundclassifier_with_metadata.tflite + labels.txt dari Teachable Machine ke folder tersebut.

Step 2: Konfigurasi pubspec & Android

Daftarkan aset di pubspec.yaml:

pubspec.yaml 
flutter:
  assets:
    - assets/ml/labels.txt
    - assets/ml/soundclassifier_with_metadata.tflite

Tambahkan izin mikrofon di android/app/src/main/AndroidManifest.xml (sebelum tag <application>):

AndroidManifest.xml 
<uses-permission android:name="android.permission.RECORD_AUDIO" />

Buka android/app/build.gradle.kts dan set minSdk = 23 agar TFLite dapat berjalan.

C. upload_controller.dart — logika baca .wav lalu klasifikasi:

lib/upload_controller.dart 
import 'dart:io';
import 'dart:typed_data';
import 'package:file_picker/file_picker.dart';
import 'package:flutter/services.dart';
import 'package:get/get.dart';
import 'package:tflite_flutter/tflite_flutter.dart';

class UploadController extends GetxController {
  // Variabel reaktif yang dipantau UI
  final fileName = 'Belum ada file'.obs;
  final label = '-'.obs;
  final confidence = 0.0.obs;

  Interpreter? _interpreter;
  List<String> _labels = [];
  static const int _inputSize = 15600; // 1 detik @ 16kHz

  @override
  void onInit() {
    super.onInit();
    _load();
  }

  @override
  void onClose() {
    _interpreter?.close();
    super.onClose();
  }

  Future<void> _load() async {
    _interpreter = await Interpreter.fromAsset(
        'assets/ml/soundclassifier_with_metadata.tflite');
    final raw = await rootBundle.loadString('assets/ml/labels.txt');
    // Format Teachable Machine: "0 Tepuk" → ambil "Tepuk"
    _labels = raw.split('\n')
        .where((l) => l.trim().isNotEmpty)
        .map((l) => l.split(' ').sublist(1).join(' '))
        .toList();
  }

  Future<void> pickAndClassify() async {
    final result = await FilePicker.platform.pickFiles(type: FileType.audio);
    if (result == null || result.files.isEmpty) return;

    final path = result.files.first.path;
    if (path == null) return;
    fileName.value = result.files.first.name;
    label.value = 'Memproses...';

    // Lewati 44 byte header WAV, baca data PCM 16-bit
    final bytes = await File(path).readAsBytes();
    final pcm = bytes.sublist(44).buffer
        .asInt16List(bytes.offsetInBytes + 44, (bytes.length - 44) ~/ 2);

    // Ambil 15600 sample pertama, kalau kurang isi nol
    final samples = List<int>.filled(_inputSize, 0);
    for (var i = 0; i < _inputSize && i < pcm.length; i++) {
      samples[i] = pcm[i];
    }
    _runModel(samples);
  }

  void _runModel(List<int> pcm) {
    if (_interpreter == null) return;

    // Normalisasi int16 ke float [-1, 1]
    final input = [pcm.map((e) => e / 32768.0).toList()];
    final output = List.filled(1, List.filled(_labels.length, 0.0));
    _interpreter!.run(input, output);

    // Ambil index dengan probabilitas tertinggi
    final probs = output[0];
    var bestIdx = 0;
    for (var i = 1; i < probs.length; i++) {
      if (probs[i] > probs[bestIdx]) bestIdx = i;
    }
    label.value = _labels[bestIdx];
    confidence.value = probs[bestIdx];
  }
}

E. realtime_controller.dart — stream mic + klasifikasi tiap ±1 detik:

lib/realtime_controller.dart 
import 'dart:async';
import 'dart:typed_data';
import 'package:flutter/services.dart';
import 'package:get/get.dart';
import 'package:permission_handler/permission_handler.dart';
import 'package:record/record.dart';
import 'package:tflite_flutter/tflite_flutter.dart';

class RealtimeController extends GetxController {
  final isRecording = false.obs;
  final label = 'Tekan mulai'.obs;
  final confidence = 0.0.obs;

  final _recorder = AudioRecorder();
  StreamSubscription<Uint8List>? _sub;
  Interpreter? _interpreter;
  List<String> _labels = [];
  final List<int> _buffer = [];

  static const int _inputSize = 15600; // 1 detik @ 16kHz

  @override
  void onInit() {
    super.onInit();
    _load();
  }

  @override
  void onClose() {
    _stop();
    _recorder.dispose();
    _interpreter?.close();
    super.onClose();
  }

  Future<void> _load() async {
    _interpreter = await Interpreter.fromAsset(
        'assets/ml/soundclassifier_with_metadata.tflite');
    final raw = await rootBundle.loadString('assets/ml/labels.txt');
    _labels = raw.split('\n')
        .where((l) => l.trim().isNotEmpty)
        .map((l) => l.split(' ').sublist(1).join(' '))
        .toList();
  }

  Future<void> toggle() async {
    if (isRecording.value) {
      await _stop();
    } else {
      await _start();
    }
  }

  Future<void> _start() async {
    final granted = await Permission.microphone.request().isGranted;
    if (!granted) {
      label.value = 'Izin mikrofon ditolak';
      return;
    }

    final stream = await _recorder.startStream(const RecordConfig(
      encoder: AudioEncoder.pcm16bits,
      sampleRate: 16000,
      numChannels: 1,
    ));

    _buffer.clear();
    isRecording.value = true;
    label.value = 'Mendengarkan...';

    _sub = stream.listen((data) {
      // Setiap chunk PCM 16-bit, dorong ke buffer
      final pcm = data.buffer.asInt16List(
          data.offsetInBytes, data.lengthInBytes ~/ 2);
      _buffer.addAll(pcm);

      // Setiap kali buffer punya cukup sample untuk 1 detik audio
      if (_buffer.length >= _inputSize) {
        final samples = _buffer.sublist(_buffer.length - _inputSize);
        // sliding window: simpan setengah, geser
        _buffer.removeRange(0, _buffer.length - _inputSize ~/ 2);
        _runModel(samples);
      }
    });
  }

  Future<void> _stop() async {
    await _sub?.cancel();
    _sub = null;
    await _recorder.stop();
    isRecording.value = false;
    label.value = 'Tekan mulai';
    confidence.value = 0.0;
  }

  void _runModel(List<int> pcm) {
    if (_interpreter == null) return;
    final input = [pcm.map((e) => e / 32768.0).toList()];
    final output = List.filled(1, List.filled(_labels.length, 0.0));
    _interpreter!.run(input, output);

    final probs = output[0];
    var best = 0;
    for (var i = 1; i < probs.length; i++) {
      if (probs[i] > probs[best]) best = i;
    }
    label.value = _labels[best];
    confidence.value = probs[best];
  }
}

Konsep penting: Sliding Window

Mic kita stream terus-menerus, tapi model hanya menerima 15600 sample (≈1 detik @ 16kHz). Jadi kita tampung di buffer. Tiap kali buffer sudah cukup, ambil 1 detik terakhir, jalankan model, lalu sisakan setengah agar suara berikutnya overlap — supaya tepuk yang jatuh di pinggir window tetap terdeteksi.

Step 5: Menjalankan Aplikasi

Hubungkan HP fisik (emulator biasanya tidak punya mic) lalu jalankan flutter run. Anda akan disambut halaman menu dengan 2 tombol — upload atau realtime. Coba dan lihat label + confidence-bar berubah otomatis.

Tantangan Audio ML (Penting)

Audio sangat rentan terhadap perubahan lingkungan (Noise). Model yang dilatih di ruangan tertutup (hening) mungkin akan gagal mengenali suara jika Anda mengujinya di ruangan yang ramai. Pastikan merekam sampel Background Noise dari berbagai kondisi ruangan (kipas angin, jalanan) agar akurasi model lebih tangguh di dunia nyata.
