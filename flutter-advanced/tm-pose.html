Modul 2.3: Pose Project

Estimasi: 60 Menit
Praktikum

Pose Project menggunakan model PoseNet untuk mengekstraksi titik kunci tubuh (mata, telinga, bahu, siku, pergelangan tangan, pinggul, lutut, kaki) lalu meng-klasifikasi pose berdasarkan koordinat titik-titik tersebut. Sangat cocok untuk aplikasi kebugaran, fisioterapi, atau game gerak.

Langkah Praktikum 1: Membuat Model Pose

Kita akan melatih model untuk mengenali dua pose: Berdiri dan Squat.

Step 1: Persiapan

Buka Teachable Machine → pilih Pose Project → Standard pose model.

Step 2: Pengumpulan Data

Definisi Kelas

Buat 2 kelas: Berdiri dan Squat. Tambahkan kelas Background bila ingin lebih akurat.

Posisi Kamera

Pastikan seluruh tubuh (kepala sampai kaki) masuk frame. Berdiri agak jauh dari webcam.

Variasi Sudut

Ambil minimal 100 sample tiap kelas, dengan variasi sudut (depan, samping) dan kedalaman squat.

Apa yang Sebenarnya Dipelajari Model?

Berbeda dengan Image Project yang belajar dari piksel, Pose Project belajar dari koordinat 17 keypoint tubuh. PoseNet menggambar titik di siku, lutut, dst — dan model klasifikasi belajar pola geometrinya. Inilah kenapa pose model bisa bekerja meski pakaian dan latar berubah.

Step 3: Train & Export ke TFLite

  1. Klik Train Model dan tunggu sampai selesai.
  2. Tes di panel Preview: berdiri kemudian squat, perhatikan persentase berubah.
  3. Klik Export Model → tab TensorFlow Lite → pilih Floating point (model pose berbeda dengan image, gunakan float).
  4. Unduh ZIP berisi model.tflite dan labels.txt.

Langkah Praktikum 2: Implementasi di Flutter dengan GetX

Kita buat project baru sederhana. Struktur flat (tanpa folder modules/bindings) — semua file ada di lib/.

Pendekatan yang Kita Pakai

Model pose Teachable Machine sebenarnya menerima gambar sebagai input (internalnya pakai PoseNet untuk ekstrak keypoint). Jadi flow Flutter-nya: ambil foto dari galeri/kamera → resize ke 257×257 (input standar PoseNet di Teachable Machine) → jalankan model → tampilkan label probabilitas.

Step 1: Buat Project & Dependencies

Terminal 
flutter create klasifikasi_pose
cd klasifikasi_pose
flutter pub add get tflite_flutter image_picker image

Step 2: Tambahkan Aset Model

Buat folder assets/ml/, salin model.tflite dan labels.txt ke dalamnya. Lalu daftarkan di pubspec.yaml:

pubspec.yaml 
flutter:
  assets:
    - assets/ml/model.tflite
    - assets/ml/labels.txt

Step 3: Buat Controller

Buat lib/pose_controller.dart. Semua state pakai variabel .obs agar UI otomatis reaktif.

lib/pose_controller.dart 
import 'dart:io';
import 'package:flutter/services.dart';
import 'package:get/get.dart';
import 'package:image/image.dart' as img;
import 'package:image_picker/image_picker.dart';
import 'package:tflite_flutter/tflite_flutter.dart';

class PoseController extends GetxController {
  // State reaktif
  final selectedImage = Rxn<File>();
  final results = <String, double>{}.obs;
  final isLoading = false.obs;

  Interpreter? _interpreter;
  List<String> _labels = [];
  final _picker = ImagePicker();

  // Pose model Teachable Machine pakai input 257x257 float
  static const int _inputSize = 257;

  @override
  void onInit() {
    super.onInit();
    _loadModel();
  }

  @override
  void onClose() {
    _interpreter?.close();
    super.onClose();
  }

  Future<void> _loadModel() async {
    _interpreter = await Interpreter.fromAsset('assets/ml/model.tflite');
    final raw = await rootBundle.loadString('assets/ml/labels.txt');
    _labels = raw.split('\n')
        .where((l) => l.trim().isNotEmpty)
        .map((l) => l.replaceAll(RegExp(r'^\d+\s*'), ''))
        .toList();
  }

  Future<void> pickAndClassify(ImageSource src) async {
    final picked = await _picker.pickImage(source: src);
    if (picked == null) return;

    selectedImage.value = File(picked.path);
    isLoading.value = true;
    results.clear();

    await _classify(selectedImage.value!);
    isLoading.value = false;
  }

  Future<void> _classify(File file) async {
    if (_interpreter == null) return;

    // Resize gambar ke 257x257
    final raw = img.decodeImage(file.readAsBytesSync())!;
    final resized = img.copyResize(raw, width: _inputSize, height: _inputSize);

    // Konversi piksel jadi float [-1.0 .. 1.0] (sesuai PoseNet)
    final input = List.generate(1, (_) =>
      List.generate(_inputSize, (y) =>
        List.generate(_inputSize, (x) {
          final p = resized.getPixel(x, y);
          return [
            (p.r - 127.5) / 127.5,
            (p.g - 127.5) / 127.5,
            (p.b - 127.5) / 127.5,
          ];
        })));

    // Output: probabilitas tiap kelas pose
    final output = List.filled(1, List.filled(_labels.length, 0.0));
    _interpreter!.run(input, output);

    final map = <String, double>{};
    for (var i = 0; i < _labels.length; i++) {
      map[_labels[i]] = output[0][i];
    }
    final sorted = Map.fromEntries(
      map.entries.toList()..sort((a, b) => b.value.compareTo(a.value)),
    );
    results.assignAll(sorted);
  }
}
Kenapa Normalisasi (p - 127.5) / 127.5?

PoseNet dilatih dengan gambar yang nilai pikselnya dinormalisasi ke rentang [-1, 1]. Rumusnya: (piksel - 127.5) / 127.5 mengubah angka 0-255 menjadi -1 sampai 1. Kalau salah preprocess, hasilnya akan ngaco walau model jalan tanpa error.

Step 4: Buat Halaman UI

lib/pose_page.dart 
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:image_picker/image_picker.dart';
import 'pose_controller.dart';

class PosePage extends StatelessWidget {
  const PosePage({super.key});

  @override
  Widget build(BuildContext context) {
    final c = Get.put(PoseController());

    return Scaffold(
      appBar: AppBar(title: const Text('Klasifikasi Pose')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(20),
        child: Column(children: [
          Obx(() => c.selectedImage.value == null
              ? Container(
                  height: 300,
                  decoration: BoxDecoration(
                    color: Colors.grey.shade200,
                    borderRadius: BorderRadius.circular(16),
                  ),
                  child: const Icon(Icons.accessibility_new, size: 100, color: Colors.grey),
                )
              : ClipRRect(
                  borderRadius: BorderRadius.circular(16),
                  child: Image.file(c.selectedImage.value!, height: 300, fit: BoxFit.cover),
                )),
          const SizedBox(height: 20),

          Row(mainAxisAlignment: MainAxisAlignment.center, children: [
            ElevatedButton.icon(
              onPressed: () => c.pickAndClassify(ImageSource.camera),
              icon: const Icon(Icons.camera_alt),
              label: const Text('Kamera'),
            ),
            const SizedBox(width: 12),
            OutlinedButton.icon(
              onPressed: () => c.pickAndClassify(ImageSource.gallery),
              icon: const Icon(Icons.photo_library),
              label: const Text('Galeri'),
            ),
          ]),
          const SizedBox(height: 24),

          Obx(() {
            if (c.isLoading.value) return const CircularProgressIndicator();
            return Column(
              children: c.results.entries.map((e) => Padding(
                padding: const EdgeInsets.symmetric(vertical: 6),
                child: Row(children: [
                  Expanded(flex: 3, child: Text(e.key,
                      style: const TextStyle(fontWeight: FontWeight.w600))),
                  Expanded(
                    flex: 7,
                    child: LinearProgressIndicator(value: e.value, minHeight: 14),
                  ),
                  const SizedBox(width: 12),
                  Text('${(e.value * 100).toStringAsFixed(1)}%'),
                ]),
              )).toList(),
            );
          }),
        ]),
      ),
    );
  }
}

Step 5: main.dart

lib/main.dart 
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'pose_page.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'Klasifikasi Pose',
      home: const PosePage(),
    );
  }
}
