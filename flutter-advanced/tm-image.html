Modul 2.1: Image Project

Estimasi: 45 Menit
Praktikum

Image Project adalah jenis project yang paling populer di Teachable Machine. Modul ini akan membimbing Anda mulai dari pembuatan model hingga strategi implementasi di Flutter baik melalui galeri maupun kamera real-time.

Langkah Praktikum: Membuat Model (Batu, Gunting, Kertas)

Kita akan membuat model yang dapat membedakan pose tangan Batu, Gunting, dan Kertas. Ikuti tahapan berikut secara berurutan agar Anda memahami konsep di baliknya.

Step 1: Persiapan Project

Buka Teachable Machine, klik Get Started, lalu pilih Image Project. Pilih Standard image model. Model standar memiliki kompatibilitas yang sangat luas untuk diimplementasikan ke dalam aplikasi Flutter.

Step 2: Pengumpulan Data (Dataset Gathering)

Kualitas model Anda sangat bergantung pada data yang Anda berikan (Garbage In, Garbage Out). Pada antarmuka Teachable Machine, ikuti panduan berikut saat mengambil gambar melalui webcam:

Definisi Kelas

Buat 3 kelas utama: Batu, Gunting, dan Kertas.

Jumlah Sampel

Gunakan webcam untuk mengambil minimal 100 gambar per kelas.

Variasi Data

Variasikan jarak tangan, sudut, dan latar belakang agar model lebih robust.

Step 3: Proses Training

Setelah data terkumpul, klik tombol Train Model. Pada tahap ini, Teachable Machine sedang menyesuaikan (fine-tuning) lapisan terakhir dari model MobileNet agar dapat mengenali pola spesifik dari tangan Anda.

Penting Saat Training

Jangan berpindah tab browser selama proses kalkulasi berlangsung. Browser Anda menggunakan resource secara lokal (CPU/GPU) sehingga berpindah tab dapat menyebabkan proses terhenti.

Step 4: Evaluasi & Testing

Setelah training selesai, panel Preview akan otomatis aktif. Uji coba dengan mengarahkan pose batu, gunting, atau kertas ke webcam dan perhatikan hasil persentase (confidence score).

Troubleshooting Akurasi Rendah
  • Data Tidak Seimbang (Class Imbalance): Pastikan jumlah data per kelas hampir sama (misal: 100 vs 105 vs 98).
  • Kurang Variasi Sudut: Model mungkin gagal menebak dari samping jika Anda hanya melatihnya dengan foto dari depan.
  • Latar Belakang Bias: Jika Anda memfoto "Batu" di kamar dan "Kertas" di luar, model mungkin salah belajar membedakan lokasi, bukan tangannya.

Step 5: Export Model ke TFLite

Ini adalah tahap krusial untuk menghubungkan Teachable Machine dengan Flutter. Ikuti konfigurasi export ini dengan teliti:

  1. Klik tombol Export Model pada panel Preview.
  2. Pilih tab TensorFlow Lite. (TFLite adalah format yang dioptimalkan untuk perangkat mobile seperti Android/iOS).
  3. Pilih jenis conversion Quantized. Model quantized mengorbankan sedikit sekali akurasi namun menghasilkan ukuran file yang ~4x lebih kecil dan komputasi yang jauh lebih cepat di memori HP.
  4. Klik Download my model. File ZIP yang terunduh akan berisi dua file: model_unquant.tflite dan daftar label di dalam labels.txt.

Langkah Praktikum 2: Implementasi di Flutter dengan GetX

Kita akan membuat project Flutter baru yang sederhana — tanpa pola arsitektur rumit. Hanya 3 file: main.dart, home_controller.dart, dan home_page.dart. Kita gunakan GetX agar state (gambar, hasil prediksi, loading) cukup ditulis sekali di controller, lalu UI otomatis reaktif via Obx.

Mengapa GetX (sederhana)?

GetX punya banyak fitur (route, dependency injection, dll). Di tutorial ini kita pakai versi paling sederhana: variabel .obs + widget Obx. Tujuannya supaya kode tidak penuh setState, dan UI otomatis re-render ketika data berubah.

Step 1: Buat Project Baru

Buka terminal dan buat project Flutter baru, lalu tambahkan dependencies:

Terminal 
flutter create klasifikasi_gambar
cd klasifikasi_gambar
flutter pub add get tflite_flutter image_picker image
  • get: state management reaktif (variabel .obs + Obx).
  • tflite_flutter: menjalankan model TFLite di Flutter.
  • image_picker: mengakses galeri dan kamera HP.
  • image: resize dan mengambil nilai piksel gambar untuk preprocessing.
Catatan Platform

Android: Buka android/app/build.gradle.kts, set minSdk = 23 agar TFLite dapat berjalan.
iOS: Tambahkan key NSCameraUsageDescription dan NSPhotoLibraryUsageDescription di Info.plist untuk izin akses kamera dan galeri.

Step 2: Siapkan Assets Model

Buat folder assets/ml/ di root project. Salin file model_unquant.tflite (rename menjadi model.tflite) dan labels.txt ke folder tersebut. Lalu daftarkan di pubspec.yaml:

pubspec.yaml 
flutter:
  assets:
    - assets/ml/model.tflite
    - assets/ml/labels.txt

Struktur akhir project terlihat sederhana:

Step 3: Buat Controller (logika ML)

Buat file baru lib/home_controller.dart. Di sini semua logika ML disimpan: load model, ambil gambar, dan klasifikasi. Variabel yang diakhiri .obs akan otomatis memberi tahu UI ketika nilainya berubah.

lib/home_controller.dart 
import 'dart:io';
import 'dart:typed_data';
import 'package:flutter/services.dart';
import 'package:get/get.dart';
import 'package:image/image.dart' as img;
import 'package:image_picker/image_picker.dart';
import 'package:tflite_flutter/tflite_flutter.dart';

class HomeController extends GetxController {
  // Variabel reaktif — UI akan auto-update ketika diubah
  final selectedImage = Rxn<File>();
  final results = <String, double>{}.obs;
  final isLoading = false.obs;

  Interpreter? _interpreter;
  List<String> _labels = [];
  final _picker = ImagePicker();

  @override
  void onInit() {
    super.onInit();
    _loadModel(); // load model otomatis saat controller dibuat
  }

  @override
  void onClose() {
    _interpreter?.close();
    super.onClose();
  }

  Future<void> _loadModel() async {
    _interpreter = await Interpreter.fromAsset('assets/ml/model.tflite');
    final raw = await rootBundle.loadString('assets/ml/labels.txt');
    // Buang nomor prefix "0 Batu" → "Batu"
    _labels = raw.split('\n')
        .where((l) => l.trim().isNotEmpty)
        .map((l) => l.replaceAll(RegExp(r'^\d+\s*'), ''))
        .toList();
  }

  Future<void> pickAndClassify(ImageSource src) async {
    final picked = await _picker.pickImage(source: src);
    if (picked == null) return;

    selectedImage.value = File(picked.path);
    isLoading.value = true;
    results.clear();

    await _classify(selectedImage.value!);
    isLoading.value = false;
  }

  Future<void> _classify(File file) async {
    if (_interpreter == null) return;

    // 1. Resize gambar jadi 224x224 (sesuai input MobileNet)
    final image = img.decodeImage(file.readAsBytesSync())!;
    final resized = img.copyResize(image, width: 224, height: 224);

    // 2. Ubah piksel jadi Uint8List (untuk model Quantized 0-255)
    final buf = Uint8List(1 * 224 * 224 * 3);
    int idx = 0;
    for (var y = 0; y < 224; y++) {
      for (var x = 0; x < 224; x++) {
        final p = resized.getPixel(x, y);
        buf[idx++] = p.r.toInt();
        buf[idx++] = p.g.toInt();
        buf[idx++] = p.b.toInt();
      }
    }

    // 3. Jalankan model
    final input = buf.reshape([1, 224, 224, 3]);
    final output = Uint8List(_labels.length).reshape([1, _labels.length]);
    _interpreter!.run(input, output);

    // 4. Konversi output 0-255 ke 0.0-1.0, lalu urutkan
    final map = <String, double>{};
    for (var i = 0; i < _labels.length; i++) {
      map[_labels[i]] = (output[0][i] as int) / 255.0;
    }
    final sorted = Map.fromEntries(
      map.entries.toList()..sort((a, b) => b.value.compareTo(a.value)),
    );
    results.assignAll(sorted); // trigger Obx re-render
  }
}
Mengapa Preprocessing Penting?

Model MobileNet hanya menerima gambar berukuran 224x224 piksel. Karena kita pakai model Quantized, data piksel RGB cukup dikirim sebagai bilangan bulat Uint8 (0-255) — tidak perlu normalisasi ke float. Output model juga 0-255, lalu kita bagi 255 supaya menjadi persentase 0.0-1.0.

Step 4: Buat Halaman UI

Buat file lib/home_page.dart. UI menggunakan Obx untuk mendengarkan perubahan dari controller. Tidak ada setState sama sekali — semua otomatis ditangani GetX.

lib/home_page.dart 
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:image_picker/image_picker.dart';
import 'home_controller.dart';

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    // Get.put membuat instance controller dan menyimpannya di memori
    final c = Get.put(HomeController());

    return Scaffold(
      appBar: AppBar(title: const Text('Klasifikasi Gambar')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(20),
        child: Column(children: [
          // Preview gambar
          Obx(() => c.selectedImage.value == null
              ? Container(
                  height: 250,
                  decoration: BoxDecoration(
                    color: Colors.grey.shade200,
                    borderRadius: BorderRadius.circular(16),
                  ),
                  child: const Icon(Icons.image, size: 80, color: Colors.grey),
                )
              : ClipRRect(
                  borderRadius: BorderRadius.circular(16),
                  child: Image.file(c.selectedImage.value!, height: 250, fit: BoxFit.cover),
                )),
          const SizedBox(height: 20),

          // Tombol pilih sumber gambar
          Row(mainAxisAlignment: MainAxisAlignment.center, children: [
            ElevatedButton.icon(
              onPressed: () => c.pickAndClassify(ImageSource.camera),
              icon: const Icon(Icons.camera_alt),
              label: const Text('Kamera'),
            ),
            const SizedBox(width: 12),
            OutlinedButton.icon(
              onPressed: () => c.pickAndClassify(ImageSource.gallery),
              icon: const Icon(Icons.photo_library),
              label: const Text('Galeri'),
            ),
          ]),
          const SizedBox(height: 24),

          // Hasil prediksi — auto reaktif
          Obx(() {
            if (c.isLoading.value) return const CircularProgressIndicator();
            return Column(
              children: c.results.entries.map((e) => Padding(
                padding: const EdgeInsets.symmetric(vertical: 6),
                child: Row(children: [
                  Expanded(flex: 3, child: Text(e.key)),
                  Expanded(
                    flex: 7,
                    child: LinearProgressIndicator(value: e.value, minHeight: 14),
                  ),
                  const SizedBox(width: 12),
                  Text('${(e.value * 100).toStringAsFixed(1)}%'),
                ]),
              )).toList(),
            );
          }),
        ]),
      ),
    );
  }
}
Bagaimana Obx Bekerja?

Obx(() => ...) akan otomatis mendengarkan variabel .obs yang dipakai di dalamnya. Saat c.results berubah, hanya widget di dalam Obx tersebut yang di-rebuild — jauh lebih efisien daripada setState yang me-rebuild seluruh widget.

Ubah lib/main.dart menjadi GetMaterialApp dengan HomePage sebagai layar awal.

Langkah Praktikum 3: Versi Realtime (Opsional)

Setelah versi gambar statis berjalan, Anda bisa upgrade ke klasifikasi realtime dari stream kamera. Idenya sama persis — tinggal kita tambahkan stream frame dari kamera dan klasifikasi setiap frame yang masuk.

Tambahkan package camera:

Terminal 
flutter pub add camera

Inti perubahannya hanya ada di controller: pakai CameraController.startImageStream(). Trik kuncinya adalah flag _busy agar frame baru di-skip ketika model masih mengolah frame sebelumnya.

lib/home_controller.dart (tambahan untuk realtime) 
import 'package:camera/camera.dart';

CameraController? cameraCtrl;
bool _busy = false;

Future<void> startCamera() async {
  final cams = await availableCameras();
  cameraCtrl = CameraController(
    cams.first,
    ResolutionPreset.medium,
    enableAudio: false,
  );
  await cameraCtrl!.initialize();

  cameraCtrl!.startImageStream((frame) async {
    if (_busy) return; // skip kalau model masih sibuk
    _busy = true;
    await _classifyFrame(frame); // konversi YUV → RGB, lalu run model
    _busy = false;
  });
  update(); // trigger UI rebuild untuk CameraPreview
}
Tips Performa Realtime

• Flag busy — wajib! Tanpa ini frame menumpuk dan aplikasi nge-lag.
• Resolusi medium / low — model kita hanya menerima 224×224, percuma kirim 4K.
• Skip frame — proses 1 dari 5 frame saja sudah cukup terasa real-time.
• YUV → RGB — Android mengirim format YUV420, perlu konversi sebelum masuk ke model.
• onClose — selalu panggil cameraCtrl?.dispose() di onClose controller agar kamera tidak nyangkut.

Langkah Praktikum 4: Benchmarking Performa (Opsional)

Sangat penting untuk selalu mengukur kecepatan (waktu inferensi) model Anda secara aktual di perangkat target. Proses ini disebut dengan Benchmarking. Hal ini untuk memastikan bahwa model yang Anda buat cukup ringan untuk diakses oleh HP pengguna.

Menghitung Waktu Eksekusi 
// Mulai stopwatch sebelum fungsi run dijalankan
final sw = Stopwatch()..start();

// Eksekusi klasifikasi model
_interpreter.run(input, output);

// Hentikan stopwatch
sw.stop();
print('Waktu inferensi (ms): ${sw.elapsedMilliseconds} ms');
Target Performa MobileNet (Image Project)
Jenis Model Ukuran File Perkiraan Waktu
Standar (FP32) ~14 MB 80-100 ms / frame
Quantized (INT8) ~3.4 MB 10-45 ms / frame

*Pengujian di Flutter menunjukkan bahwa memilih model Quantized pada tahap export dari Teachable Machine adalah kunci utama untuk mendapatkan performa realtime yang optimal (di bawah 50ms) tanpa membebani memori HP.
