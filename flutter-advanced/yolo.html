Pengenalan YOLO (Object Detection)

Estimasi: 60 Menit
Teori & Praktikum

YOLO (You Only Look Once) adalah salah satu algoritma Machine Learning paling populer untuk Object Detection (Deteksi Objek) secara real-time. Tidak seperti klasifikasi gambar biasa yang hanya menebak "apa" yang ada di gambar, Object Detection menebak "apa" dan "di mana" lokasinya menggunakan kotak pembatas (Bounding Box).

1. Mengapa YOLO Sangat Populer?

Sebelum YOLO, algoritma deteksi objek menggunakan metode "Two-Stage Detector" (seperti R-CNN), di mana sistem pertama-tama mencari region yang mungkin berisi objek, lalu menjalankan klasifikasi pada setiap area tersebut. Pendekatan ini akurat namun sangat lambat.

Sesuai namanya (You Only Look Once), YOLO memandang seluruh gambar hanya satu kali (satu tahap/one-stage) menggunakan arsitektur jaringan saraf tunggal. Ini membuat YOLO sangat cepat dan efisien — ideal untuk deteksi objek realtime pada video atau kamera ponsel.

Real-Time Speed

YOLO mampu memproses frame video dengan sangat cepat (bisa mencapai 45-155 FPS), memungkinkan deteksi tanpa lag pada kamera.

Global Context

Karena memproses seluruh gambar sekaligus, YOLO memahami konteks global dan jarang membuat false positive pada background.

Single Network

Satu Neural Network memprediksi Bounding Box dan probabilitas kelas secara bersamaan secara end-to-end.

2. Konsep Kunci dalam YOLO

A. Bounding Box & Confidence Score

YOLO membagi gambar menjadi sebuah grid (misalnya 13×13). Setiap sel grid bertanggung jawab mendeteksi objek yang titik tengahnya berada di dalam sel tersebut. Sel memprediksi Bounding Box (x, y, lebar, tinggi) dan confidence score (seberapa yakin kotak itu berisi objek tertentu).

B. Intersection over Union (IoU) & NMS

YOLO sering menghasilkan banyak prediksi kotak untuk satu objek. Untuk membersihkannya, digunakan IoU (Intersection over Union) — rasio area irisan dibagi area gabungan dua kotak. Algoritma Non-Maximum Suppression (NMS) akan membuang kotak yang IoU-nya terlalu tinggi dengan kotak lain yang confidence-nya lebih besar.

3. Perkembangan Versi YOLO

  • YOLOv1–v3: Mengukuhkan dominasi YOLO di bidang deteksi objek real-time.
  • YOLOv4 & v5: Dioptimalkan untuk performa komputasi yang lebih ringan, populer untuk mobile.
  • YOLOv8 & v10 (Ultralytics): Versi modern — tidak hanya untuk Object Detection, tapi juga Instance Segmentation dan Pose Estimation dengan akurasi & efisiensi memori yang jauh lebih baik.

4. Praktikum: YOLO di Flutter dengan GetX

Kita akan membuat aplikasi sederhana untuk mendeteksi objek dari gambar yang dipilih dari galeri/kamera. Kita pakai package flutter_vision agar tidak perlu menulis post-processing NMS sendiri.

Step 1: Siapkan Model YOLO

Unduh model YOLOv8n versi TFLite yang sudah di-pretrain dengan dataset COCO (80 kelas: orang, mobil, kucing, dll) dari repo resmi Ultralytics, atau dari halaman releases YOLO. Anda akan mendapatkan:

  • yolov8n.tflite — model deteksi (ukuran ~6 MB)
  • labels.txt — daftar 80 nama kelas COCO

Step 2: Buat Project Baru

Terminal 
flutter create deteksi_yolo
cd deteksi_yolo
flutter pub add get flutter_vision image_picker

Salin yolov8n.tflite dan labels.txt ke assets/ml/, lalu daftarkan di pubspec.yaml:

pubspec.yaml 
flutter:
  assets:
    - assets/ml/yolov8n.tflite
    - assets/ml/labels.txt

Pastikan minSdk = 23 di android/app/build.gradle.kts.

Step 3: Buat Controller

lib/yolo_controller.dart 
import 'dart:io';
import 'package:flutter_vision/flutter_vision.dart';
import 'package:get/get.dart';
import 'package:image_picker/image_picker.dart';

class YoloController extends GetxController {
  final _vision = FlutterVision();
  final _picker = ImagePicker();

  // State reaktif
  final selectedImage = Rxn<File>();
  final detections = <Map<String, dynamic>>[].obs;
  final isLoading = false.obs;
  final imageSize = Size.zero.obs;

  @override
  void onInit() {
    super.onInit();
    _loadModel();
  }

  @override
  void onClose() {
    _vision.closeYoloModel();
    super.onClose();
  }

  Future<void> _loadModel() async {
    await _vision.loadYoloModel(
      modelPath: 'assets/ml/yolov8n.tflite',
      labels: 'assets/ml/labels.txt',
      modelVersion: 'yolov8',
      numThreads: 2,
      useGpu: false,
    );
  }

  Future<void> pickAndDetect(ImageSource src) async {
    final picked = await _picker.pickImage(source: src);
    if (picked == null) return;

    selectedImage.value = File(picked.path);
    isLoading.value = true;

    // Baca ukuran gambar asli (untuk hitung skala bounding box)
    final bytes = await selectedImage.value!.readAsBytes();
    final decoded = await decodeImageFromList(bytes);
    imageSize.value = Size(decoded.width.toDouble(), decoded.height.toDouble());

    // Jalankan YOLO — confidence di atas 40%, IoU NMS 30%
    final result = await _vision.yoloOnImage(
      bytesList: bytes,
      imageHeight: decoded.height,
      imageWidth: decoded.width,
      iouThreshold: 0.3,
      confThreshold: 0.4,
      classThreshold: 0.5,
    );

    detections.assignAll(result);
    isLoading.value = false;
  }
}
Apa Itu Threshold di YOLO?

• confThreshold — minimum confidence agar deteksi dianggap valid (semakin tinggi = lebih sedikit false positive).
• iouThreshold — di atas berapa IoU dua kotak dianggap "menumpuk" dan salah satu dibuang oleh NMS.
• classThreshold — minimum probabilitas kelas dari hasil softmax. Biasanya cukup 0.5.

Step 4: Buat UI dengan Overlay Bounding Box

UI menampilkan gambar dengan kotak deteksi di atasnya. Kita pakai Stack + CustomPaint.

lib/yolo_page.dart 
import 'package:flutter/material.dart';
import 'package:get/get.dart';
import 'package:image_picker/image_picker.dart';
import 'yolo_controller.dart';

class YoloPage extends StatelessWidget {
  const YoloPage({super.key});

  @override
  Widget build(BuildContext context) {
    final c = Get.put(YoloController());

    return Scaffold(
      appBar: AppBar(title: const Text('Deteksi Objek YOLO')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(children: [
          Expanded(
            child: Obx(() {
              if (c.selectedImage.value == null) {
                return const Center(child: Text('Pilih gambar untuk dideteksi'));
              }
              return LayoutBuilder(builder: (_, cons) {
                return Stack(children: [
                  Image.file(c.selectedImage.value!, fit: BoxFit.contain),
                  // Gambar bounding box di atas image
                  ...c.detections.map((d) => _buildBox(d, cons.biggest, c.imageSize.value)),
                ]);
              });
            }),
          ),
          const SizedBox(height: 16),
          Obx(() => c.isLoading.value
              ? const CircularProgressIndicator()
              : Text('${c.detections.length} objek terdeteksi')),
          const SizedBox(height: 12),
          Row(mainAxisAlignment: MainAxisAlignment.center, children: [
            ElevatedButton.icon(
              onPressed: () => c.pickAndDetect(ImageSource.camera),
              icon: const Icon(Icons.camera_alt),
              label: const Text('Kamera'),
            ),
            const SizedBox(width: 12),
            OutlinedButton.icon(
              onPressed: () => c.pickAndDetect(ImageSource.gallery),
              icon: const Icon(Icons.photo_library),
              label: const Text('Galeri'),
            ),
          ]),
        ]),
      ),
    );
  }

  Widget _buildBox(Map d, Size canvas, Size orig) {
    // Skala koordinat dari ukuran gambar asli ke ukuran canvas
    final sx = canvas.width / orig.width;
    final sy = canvas.height / orig.height;

    final box = d['box'] as List;
    final x1 = (box[0] as num).toDouble() * sx;
    final y1 = (box[1] as num).toDouble() * sy;
    final w = ((box[2] as num).toDouble() - (box[0] as num).toDouble()) * sx;
    final h = ((box[3] as num).toDouble() - (box[1] as num).toDouble()) * sy;

    return Positioned(
      left: x1, top: y1, width: w, height: h,
      child: Container(
        decoration: BoxDecoration(
          border: Border.all(color: Colors.greenAccent, width: 2),
        ),
        child: Align(
          alignment: Alignment.topLeft,
          child: Container(
            color: Colors.greenAccent,
            padding: const EdgeInsets.symmetric(horizontal: 4),
            child: Text('${d['tag']} ${(d['box'][4] * 100).toStringAsFixed(0)}%',
                style: const TextStyle(color: Colors.black, fontSize: 12)),
          ),
        ),
      ),
    );
  }
}

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override

    return GetMaterialApp(

      home: const YoloPage(),
    );
  }
}

Jalankan flutter run, ambil foto dengan beberapa objek (misal foto orang dan kursi), dan amati kotak hijau yang muncul dengan label kelas + persentase.

Pengembangan Lanjut

• Realtime kamera — package flutter_vision juga punya yoloOnFrame() untuk diproses dari stream kamera.
• Custom dataset — train model YOLOv8 sendiri di Google Colab dengan dataset Anda (misal: deteksi rambu lalu lintas Indonesia), lalu export ke TFLite.
• GPU acceleration — set useGpu: true di loadYoloModel untuk performa lebih kencang (hanya jalan di device yang support).
