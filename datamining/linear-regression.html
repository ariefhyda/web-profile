Modul 17: Linear Regression

Estimasi: 50 Menit
Teori & Perhitungan

Regresi berbeda dari klasifikasi: alih-alih memprediksi kategori, ia memprediksi nilai numerik kontinu (harga rumah, suhu, nilai ujian). Linear Regression adalah bentuk paling dasar — ia mencari garis lurus terbaik yang menggambarkan hubungan antara variabel input (X) dan output (Y).

Persamaan Garis

Model linear sederhana memiliki bentuk Y = b₀ + b₁X, di mana b₀ adalah intercept (nilai Y saat X=0) dan b₁ adalah slope (kemiringan; berapa Y berubah tiap kenaikan satu unit X).

Metode Least Squares (Kuadrat Terkecil)

Garis "terbaik" adalah garis yang meminimalkan total kuadrat jarak vertikal (residual) antara titik data dan garis. Karena itu metodenya disebut Ordinary Least Squares (OLS).

b₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
b₀ = ȳ − b₁·x̄

Mengukur Kualitas Model

Beberapa metrik untuk menilai seberapa baik garis regresi mencocokkan data:

  1. MSE (Mean Squared Error) — Rata-rata kuadrat residual. Makin kecil makin baik; menghukum kesalahan besar.
  2. RMSE (Root MSE) — Akar dari MSE, satuannya sama dengan Y sehingga lebih mudah ditafsirkan.
  3. MAE (Mean Absolute Error) — Rata-rata nilai absolut residual; lebih tahan terhadap pencilan.
  4. R² (Koefisien Determinasi) — Proporsi variasi Y yang dijelaskan model. Rentang 0–1; makin dekat 1 makin baik.
Multiple Linear Regression

Bila input lebih dari satu fitur, modelnya menjadi Y = b₀ + b₁X₁ + b₂X₂ + … + bₙXₙ. Konsepnya sama, hanya garis menjadi bidang/hyperplane. Perhatikan multikolinearitas (fitur yang saling berkorelasi tinggi) yang dapat mengganggu estimasi koefisien.

Interaktif: Cari Garis Terbaik

Geser slope (b₁) dan intercept (b₀) untuk menggerakkan garis. Garis putus-putus adalah residual, dan SSE (total kuadrat residual) menunjukkan seberapa buruk garisnya. Coba perkecil SSE serendah mungkin, lalu tekan tombol untuk melihat solusi least squares.

Implementasi di Python

linear_regression_sklearn.py 
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Data dari studi kasus (X harus 2D)
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2, 4, 5, 4, 5])

model = LinearRegression()
model.fit(X, y)

print("Intercept (b0):", model.intercept_)   # ≈ 2.2
print("Slope (b1)    :", model.coef_[0])    # ≈ 0.6

# Prediksi & evaluasi
y_pred = model.predict(X)
print("MSE:", mean_squared_error(y, y_pred))
print("R² :", r2_score(y, y_pred))
print("Prediksi X=6:", model.predict([[6]])[0])  # 2.2 + 0.6*6 = 5.8
