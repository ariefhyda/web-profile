Modul 18: Logistic Regression

Estimasi: 50 Menit
Teori & Perhitungan

Meskipun namanya mengandung kata "regression", Logistic Regression sebenarnya adalah algoritma klasifikasi. Ia memprediksi probabilitas sebuah data masuk ke suatu kelas (mis. lulus/gagal, spam/bukan, sakit/sehat) — sebuah nilai antara 0 dan 1.

Kenapa Bukan Linear Regression?

Linear regression menghasilkan nilai dari −∞ sampai +∞, sehingga tidak cocok untuk probabilitas (yang harus 0–1). Logistic Regression "menekuk" output garis linear lewat fungsi sigmoid agar selalu berada di rentang 0–1.

Fungsi Sigmoid

Inti dari logistic regression adalah fungsi sigmoid (logistik). Ia mengubah skor linear z = b₀ + b₁X menjadi probabilitas berbentuk huruf "S".

σ(z) = 1 / (1 + e−z)   dengan   z = b₀ + b₁X

Visualisasi Kurva Sigmoid

Perhatikan: saat z besar positif, σ(z) → 1; saat z besar negatif, σ(z) → 0; tepat di z = 0, σ(z) = 0.5. Garis putus-putus pada 0.5 adalah ambang keputusan (decision boundary) default.

σ(z) Ambang 0.5 Decision boundary

Aturan Keputusan

  1. Jika σ(z) ≥ 0.5 → prediksi kelas 1 (positif).
  2. Jika σ(z) < 0.5 → prediksi kelas 0 (negatif).

Ambang 0.5 bisa digeser sesuai kebutuhan. Contohnya pada diagnosis penyakit, kita mungkin menurunkan ambang agar lebih sensitif (menangkap lebih banyak kasus positif walau ada false alarm).

Studi Kasus: Lulus Berdasarkan Jam Belajar

Misalkan model terlatih menghasilkan koefisien b₀ = −4 dan b₁ = 1.5. Mari hitung probabilitas lulus untuk beberapa nilai jam belajar (X).

Perhitungan
X = 1 jam → z = −4 + 1.5(1) = −2.5 → σ = 0.076 → GAGAL
X = 2.67 jam → z = 0 → σ = 0.50 → batas keputusan
X = 4 jam → z = −4 + 1.5(4) = 2.0 → σ = 0.881 → LULUS
Odds & Log-Odds

Koefisien b₁ ditafsirkan melalui odds ratio. Persamaan logistik setara dengan ln(p / (1−p)) = b₀ + b₁X — artinya logistic regression sebenarnya memodelkan log-odds secara linear. Tiap kenaikan satu unit X mengalikan odds dengan eb₁.

Fungsi Biaya: Log-Loss

Logistic regression tidak memakai MSE, melainkan Binary Cross-Entropy (Log-Loss). Fungsi ini menghukum prediksi yang percaya diri tetapi salah dengan sangat berat, dan dioptimalkan menggunakan Gradient Descent (atau Maximum Likelihood Estimation).

Loss = −[ y·log(p) + (1−y)·log(1−p) ]

Linear vs Logistic Regression

Linear Regression

  • Output: nilai kontinu (−∞ … +∞)
  • Tugas: regresi (prediksi angka)
  • Fungsi biaya: MSE
  • Garis lurus

Logistic Regression

  • Output: probabilitas (0 … 1)
  • Tugas: klasifikasi
  • Fungsi biaya: Log-Loss
  • Kurva sigmoid (S)

Implementasi di Python

logistic_regression_sklearn.py 
import numpy as np
from sklearn.linear_model import LogisticRegression

# Jam belajar (X) dan hasil (0=gagal, 1=lulus)
X = np.array([[0.5], [1], [1.5], [2], [3], [4], [5]])
y = np.array([0, 0, 0, 0, 1, 1, 1])

model = LogisticRegression()
model.fit(X, y)

# Probabilitas kelas 1 (lulus) untuk 4 jam belajar
prob = model.predict_proba([[4]])[0][1]
print(f"P(lulus | 4 jam) = {prob:.2f}")
print("Prediksi kelas  :", model.predict([[4]])[0])

# Koefisien hasil pelatihan
print("b0:", model.intercept_[0], "| b1:", model.coef_[0][0])
