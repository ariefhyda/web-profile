Modul 9: K-Means Clustering

Estimasi: 60 Menit
Teori & Interaktif Visual

Berbeda dengan algoritma yang telah kita pelajari sebelumnya (KNN, Naïve Bayes, Decision Tree) yang merupakan Supervised Learning (Data memiliki target/label), K-Means Clustering adalah algoritma Unsupervised Learning.

Tujuan dari K-Means adalah untuk menemukan kelompok (cluster) dalam data di mana label atau targetnya tidak diketahui. Algoritma ini akan mengelompokkan data yang memiliki karakteristik mirip ke dalam satu cluster yang sama. Huruf "K" merepresentasikan jumlah cluster yang ingin dibentuk.

Cara Kerja K-Means
  1. Tentukan jumlah cluster K.
  2. Pilih K titik secara acak dari dataset sebagai pusat cluster awal (Centroid).
  3. Assignment: Hitung jarak setiap data ke seluruh centroid, lalu kelompokkan data ke centroid yang paling dekat.
  4. Update: Hitung nilai rata-rata (mean) dari setiap kelompok untuk mencari titik pusat yang baru, lalu geser centroid ke titik tersebut.
  5. Ulangi langkah 3 dan 4 sampai centroid tidak lagi berpindah (Konvergen).

Rumus K-Means

Secara matematis, K-Means bekerja dengan dua rumus inti yang dijalankan bergantian: menghitung jarak setiap titik ke centroid, lalu memperbarui posisi centroid dengan rata-rata anggotanya. Tujuan akhirnya adalah meminimalkan total kuadrat jarak (WCSS).

1. Jarak Euclidean (Assignment)

Untuk menentukan centroid terdekat, dihitung jarak Euclidean antara titik data x dan centroid c. Sebuah titik akan masuk ke cluster dengan jarak terkecil.

d(x, c) = √( (x₁ − c₁)² + (x₂ − c₂)² + … + (xₙ − cₙ)² )

2. Update Centroid (Mean)

Posisi centroid baru (μ) untuk cluster j adalah rata-rata dari seluruh titik yang menjadi anggotanya, di mana n₋ adalah jumlah anggota cluster tersebut.

μ₋ = (1 / n₋) · Σ xᵢ   (untuk setiap xᵢ ∈ cluster j)

3. Within-Cluster Sum of Squares (WCSS)

WCSS (juga disebut inertia) mengukur seberapa rapat tiap cluster, yaitu total kuadrat jarak setiap titik ke centroid clusternya. Algoritma berusaha membuat nilai ini sekecil mungkin.

WCSS = Σ₋́₁ Σₓ₋ₙ₋ₐ₃ₕₖₕ₌ ‖ xᵢ − μ₋ ‖²

Contoh Perhitungan Manual

Misalkan kita punya 5 titik data 1 dimensi: 2, 4, 6, 10, 12. Kita ingin membentuk K = 2 cluster. Mari kita jalankan satu iterasi penuh secara manual.

Langkah 0 — Inisialisasi Centroid

Pilih dua centroid awal secara acak, misal c₁ = 2 dan c₂ = 12.

Iterasi 1 — Assignment

Hitung jarak setiap titik ke kedua centroid (dalam 1D, jarak = nilai mutlak selisih), lalu pilih yang terdekat.

Titik (x)|x − c₁| (c₁=2)|x − c₂| (c₂=12)Cluster

Hasil: C1 = {2, 4, 6} dan C2 = {10, 12}.

Iterasi 1 — Update Centroid

Hitung rata-rata tiap cluster sebagai centroid baru:

c₁ = (2 + 4 + 6) / 3 = 4
c₂ = (10 + 12) / 2 = 11

Iterasi 2 — Cek Konvergensi

Ulangi assignment dengan centroid baru (c₁ = 4, c₂ = 11). Titik 2, 4, 6 tetap lebih dekat ke 4; titik 10, 12 tetap lebih dekat ke 11. Karena tidak ada titik yang berpindah cluster, algoritma dinyatakan konvergen.

Menghitung WCSS akhir
WCSS = [(2−4)² + (4−4)² + (6−4)²] + [(10−11)² + (12−11)²]
WCSS = [4 + 0 + 4] + [1 + 1] = 10

Nilai WCSS = 10 inilah yang dibandingkan antar-nilai K pada Metode Elbow di bawah.

Metode Elbow (Mencari K Optimal)

Dalam praktiknya, kita seringkali tidak tahu berapa nilai K (jumlah cluster) yang paling tepat. Salah satu cara paling umum adalah menggunakan Elbow Method (Metode Siku).

Idenya: kita menjalankan K-Means berulang kali dengan nilai K yang berbeda (misal K = 1 sampai 10), lalu untuk setiap K kita menghitung WCSS (Within-Cluster Sum of Squares) — total kuadrat jarak setiap titik ke centroid clusternya.

Rumus WCSS

WCSS untuk sebuah nilai K dihitung dengan menjumlahkan kuadrat jarak seluruh titik ke centroid masing-masing cluster:

WCSS(K) = Σj=1K   Σxᵢ ∈ C₋   ‖ xᵢ − μ₋ ‖²

dengan C₋ = himpunan titik pada cluster ke-j, dan μ₋ = centroid cluster ke-j. Di scikit-learn nilai ini tersedia langsung melalui atribut kmeans.inertia_.

Cara membaca grafiknya

Saat WCSS diplot terhadap K, nilainya selalu turun seiring K bertambah (semakin banyak cluster, semakin dekat titik ke centroidnya — pada K = jumlah data, WCSS = 0). Yang kita cari adalah "siku" (elbow): titik di mana penurunan WCSS mulai melambat drastis. Setelah siku itu, menambah cluster hanya memberi sedikit perbaikan, jadi K di siku tersebut dianggap optimal.

Cara cepat menemukan siku secara otomatis

Hitung selisih penurunan WCSS antar-K. Siku berada di K di mana penurunan WCSS anjlok paling tajam dibanding penurunan berikutnya — yaitu K dengan selisih kedua (second difference) terbesar:

Δ₁(K) = WCSS(K−1) − WCSS(K)
Δ₂(K) = Δ₁(K) − Δ₁(K+1)   →  pilih K dengan Δ₂ terbesar

Tips

Karena skala antar-fitur berbeda jauh (mis. Pendapatan vs Skor Belanja), lakukan normalisasi (Min-Max atau Standard Scaler) sebelum menjalankan K-Means agar jarak Euclidean tidak didominasi fitur berskala besar.

Implementasi di Python

kmeans_clustering.py 
from sklearn.cluster import KMeans
import pandas as pd
import matplotlib.pyplot as plt

# 1. Load Data (Pastikan hanya fitur numerik, tidak ada label target!)
df = pd.read_csv('customer_data.csv')
X = df[['Annual Income', 'Spending Score']]

# 2. Elbow Method untuk mencari K optimal
wcss = []
for i in range(1, 11):
    kmeans = KMeans(n_clusters=i, init='k-means++', random_state=42)
    kmeans.fit(X)
    wcss.append(kmeans.inertia_) # inertia_ = nilai WCSS

# (Optional) Plot grafik WCSS vs K untuk melihat sikunya

# 3. Latih model dengan K yang terpilih (misal siku di K=5)
kmeans = KMeans(n_clusters=5, init='k-means++', random_state=42)
y_kmeans = kmeans.fit_predict(X)

# 4. Lihat Hasil Cluster
df['Cluster'] = y_kmeans
print(df.head())
