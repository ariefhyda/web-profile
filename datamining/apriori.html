Modul 15: Association Rule — Algoritma Apriori

Estimasi: 55 Menit
Teori & Studi Kasus

Association Rule Mining mencari hubungan "jika-maka" antar item dalam data transaksi. Contoh klasiknya adalah Market Basket Analysis: "Jika pelanggan membeli roti dan susu, kemungkinan besar ia juga membeli telur." Aturan ini ditulis sebagai {Roti, Susu} → {Telur}.

Tiga Metrik Kunci

• Support — Seberapa sering itemset muncul di seluruh transaksi.
• Confidence — Seberapa sering aturan benar (probabilitas konsekuen jika anteseden ada).
• Lift — Seberapa kuat hubungan dibanding kebetulan. Lift > 1 = korelasi positif.

Rumus Metrik

Support(A) = (Transaksi memuat A) / (Total transaksi)
Confidence(A → B) = Support(A ∪ B) / Support(A)
Lift(A → B) = Confidence(A → B) / Support(B)

Prinsip Apriori (Apriori Property)

"Jika sebuah itemset jarang (tidak frequent), maka semua superset-nya pasti juga jarang." Prinsip ini memungkinkan kita memangkas (pruning) banyak kandidat tanpa menghitungnya — inti efisiensi Apriori.

Langkah 1 — Itemset 1 Item (C1 → L1)

Hitung support tiap item. Buang yang < minimum support (2).

Semua item lolos. L1 = {Roti, Susu, Telur, Bir}.

Langkah 2 — Itemset 2 Item (C2 → L2)

Gabungkan pasangan dari L1 lalu hitung support-nya.

Pasangan ItemCountStatus

Semua pasangan memiliki count ≥ 2 sehingga semuanya lolos menjadi L2.

Langkah 3 — Itemset 3 Item (C3 → L3)

Gabungkan menjadi triplet. Hanya kandidat yang seluruh sub-pasangannya frequent yang perlu dihitung.

TripletCountStatus
{Roti, Susu, Telur}2✅ Lolos
{Susu, Telur, Bir}2✅ Lolos
{Roti, Susu, Bir}1❌ Dibuang
{Roti, Telur, Bir}2✅ Lolos

Langkah 4 — Bangun Aturan & Hitung Confidence

Dari itemset frequent {Roti, Susu, Telur} (support = 2/5 = 0.4), kita turunkan aturan dan hitung kekuatannya.

Contoh Aturan
Aturan: {Roti, Susu} → {Telur}
Support({Roti,Susu,Telur}) = 2/5 = 0.40
Support({Roti,Susu}) = 3/5 = 0.60
Confidence = 0.40 / 0.60 = 0.67 (67%)
Lift = 0.67 / Support(Telur) = 0.67 / 0.80 = 0.83

Confidence 67% cukup baik, tetapi Lift = 0.83 (< 1) menandakan bahwa membeli Roti+Susu justru sedikit menurunkan peluang membeli Telur dibanding rata-rata. Inilah mengapa Lift penting: confidence tinggi belum tentu berarti korelasi nyata.

Implementasi di Python

Pustaka mlxtend menyediakan implementasi Apriori yang siap pakai bersama pandas.

apriori_mlxtend.py 
import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

dataset = [
    ['Roti', 'Susu'],
    ['Roti', 'Telur', 'Bir'],
    ['Susu', 'Telur', 'Bir'],
    ['Roti', 'Susu', 'Telur', 'Bir'],
    ['Roti', 'Susu', 'Telur'],
]

# 1. Ubah ke format one-hot (True/False per item)
te = TransactionEncoder()
arr = te.fit(dataset).transform(dataset)
df = pd.DataFrame(arr, columns=te.columns_)

# 2. Cari frequent itemset (min support 40%)
freq = apriori(df, min_support=0.4, use_colnames=True)

# 3. Bangun aturan dengan confidence minimal 60%
rules = association_rules(freq, metric="confidence", min_threshold=0.6)
print(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']])
