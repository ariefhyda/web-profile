Modul 14: DBSCAN (Density-Based Clustering)

Estimasi: 45 Menit
Teori & Visualisasi

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) mengelompokkan data berdasarkan kepadatan. Wilayah yang padat titik dianggap satu klaster, sedangkan titik di wilayah jarang dianggap noise (pencilan). Berbeda dengan K-Means, DBSCAN tidak perlu menentukan jumlah klaster (k) di awal dan mampu menemukan klaster berbentuk tidak beraturan.

Dua Parameter Utama

• eps (ε): Radius ketetanggaan. Seberapa dekat dua titik agar dianggap "bertetangga".
• MinPts: Jumlah minimum titik (termasuk dirinya sendiri) di dalam radius ε agar sebuah titik disebut core point.

Tiga Jenis Titik

  1. Core Point — Memiliki minimal MinPts tetangga dalam radius ε. Ini adalah "jantung" klaster.
  2. Border Point — Tetangganya kurang dari MinPts, TAPI masih berada dalam radius ε dari sebuah core point. Ia ikut bergabung ke klaster.
  3. Noise Point — Bukan core maupun border. Tidak masuk klaster manapun, ditandai sebagai pencilan (label −1).

Visualisasi Kepadatan

Pada ilustrasi berikut (MinPts = 4), lingkaran putus-putus menunjukkan radius ε di sekitar sebuah core point. Titik ungu padat membentuk klaster, titik biru adalah border, dan titik merah yang terisolasi adalah noise.

Langkah Algoritma

  1. Pilih satu titik yang belum dikunjungi.
  2. Hitung berapa tetangganya dalam radius ε. Jika ≥ MinPts, titik menjadi core point dan klaster baru dimulai.
  3. Perluas klaster: semua tetangga ikut bergabung. Jika tetangga juga core point, tetangganya pun ditarik masuk (density-reachable) secara rekursif.
  4. Jika tetangga < MinPts dan tidak dekat core manapun, tandai sebagai noise (bisa berubah jadi border di kemudian hari).
  5. Ulangi hingga semua titik dikunjungi.
Cara Memilih eps

Gunakan k-distance graph: hitung jarak setiap titik ke tetangga ke-k (k = MinPts), urutkan, lalu plot. Titik "siku" (elbow) pada grafik adalah nilai ε yang baik. Untuk MinPts, aturan praktis: MinPts ≥ dimensi + 1, sering dipakai nilai 4 untuk data 2D.

DBSCAN vs K-Means

DBSCAN

  • Tidak perlu tentukan jumlah klaster
  • Menangani bentuk klaster sembarang
  • Otomatis mendeteksi noise/pencilan
  • Kesulitan jika kepadatan klaster bervariasi

K-Means

  • Harus tentukan k di awal
  • Cenderung membentuk klaster bulat
  • Setiap titik dipaksa masuk klaster
  • Cepat & sederhana untuk data besar

Interaktif: Atur eps & MinPts

Geser kedua parameter dan lihat bagaimana algoritma DBSCAN mengklasifikasi ulang setiap titik menjadi core, border, atau noise secara langsung. Lingkaran putus-putus menunjukkan ukuran radius ε. Perhatikan: ε terlalu kecil → semua jadi noise; ε terlalu besar → semua menyatu jadi satu klaster.

Implementasi di Python

dbscan_sklearn.py 
from sklearn.cluster import DBSCAN
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_moons
import numpy as np

# Data berbentuk bulan sabit (tidak bisa dipisah K-Means)
X, _ = make_moons(n_samples=300, noise=0.06, random_state=42)
X = StandardScaler().fit_transform(X)

# eps = radius, min_samples = MinPts
db = DBSCAN(eps=0.3, min_samples=5).fit(X)
labels = db.labels_

# Label -1 berarti noise
n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise = list(labels).count(-1)
print("Jumlah klaster:", n_clusters)
print("Jumlah noise  :", n_noise)
