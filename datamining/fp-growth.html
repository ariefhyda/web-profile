Modul 16: FP-Growth (Frequent Pattern Growth)

Estimasi: 50 Menit
Teori & Visualisasi

FP-Growth adalah algoritma asosiasi yang menyelesaikan masalah terbesar Apriori: pembuatan kandidat yang sangat banyak dan pemindaian database berulang-ulang. FP-Growth memadatkan seluruh data ke dalam struktur pohon ringkas bernama FP-Tree, lalu menambang pola langsung dari pohon itu — tanpa generate kandidat sama sekali.

Ide Inti

Apriori memindai database puluhan kali (sekali untuk tiap level itemset). FP-Growth hanya memindai database dua kali: sekali untuk menghitung frekuensi item, sekali lagi untuk membangun FP-Tree. Sisanya cukup menelusuri pohon di memori.

Langkah 1 — Hitung & Urutkan Item

Gunakan data transaksi yang sama seperti pada modul Apriori (minimum support = 2). Pertama, hitung frekuensi tiap item dan urutkan menurun.

ItemCountUrutan Prioritas
Roti41
Susu42
Telur43
Bir34

Saat seri (Roti=Susu=Telur=4), urutan ditentukan secara konsisten (mis. alfabetis/urutan kemunculan). Di sini kita pakai urutan: Roti > Susu > Telur > Bir.

Langkah 2 — Susun Ulang Setiap Transaksi

Tiap transaksi diurutkan ulang mengikuti prioritas di atas, agar item populer berbagi cabang yang sama di pohon.

TransaksiItem (asli)Setelah diurutkan
T1Roti, SusuRotiSusu
T2Roti, Telur, BirRotiTelurBir
T3Susu, Telur, BirSusuTelurBir
T4Roti, Susu, Telur, BirRotiSusuTelurBir
T5Roti, Susu, TelurRotiSusuTelur

Langkah 3 — Bangun FP-Tree

Setiap transaksi "ditanam" ke pohon mulai dari root (null). Jika sebuah prefix sudah ada, counter node-nya cukup ditambah; jika belum, cabang baru dibuat. Angka pada setiap node adalah jumlah transaksi yang melewatinya.

null (root)
Roti : 4
Susu : 3
Telur : 2
Bir : 1
Telur : 1
Bir : 1
Susu : 1
Telur : 1
Bir : 1

Perhatikan T1–T2–T4–T5 berbagi prefix "Roti" sehingga node Roti bernilai 4. Hanya T3 (diawali Susu) yang membentuk cabang terpisah. Inilah kompresi yang membuat FP-Growth hemat memori.

Langkah 4 — Tambang Pola dari Pohon

Mulai dari item paling jarang (Bir), bangun conditional pattern base — yaitu kumpulan prefix path yang berakhir di item tersebut beserta count-nya. Dari sini disusun conditional FP-Tree, lalu pola frequent diturunkan secara rekursif.

Contoh: Conditional Pattern Base untuk "Bir"
{Roti, Susu, Telur} : 1
{Roti, Telur} : 1
{Susu, Telur} : 1
→ Item yang frequent bersama Bir: Telur (3)
→ Pola frequent: {Telur, Bir} : 3

Interaktif: Bangun FP-Tree

Tanam transaksi satu per satu (sudah diurutkan menurut prioritas Roti > Susu > Telur > Bir) dan saksikan pohon tumbuh. Node yang baru terbentuk atau bertambah hitungannya akan disorot hijau. Perhatikan bagaimana transaksi berbagi prefix yang sama.

Implementasi di Python

API-nya hampir identik dengan Apriori di mlxtend — cukup ganti fungsinya menjadi fpgrowth.

fpgrowth_mlxtend.py 
import pandas as pd
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import fpgrowth, association_rules

dataset = [
    ['Roti', 'Susu'],
    ['Roti', 'Telur', 'Bir'],
    ['Susu', 'Telur', 'Bir'],
    ['Roti', 'Susu', 'Telur', 'Bir'],
    ['Roti', 'Susu', 'Telur'],
]

te = TransactionEncoder()
df = pd.DataFrame(te.fit(dataset).transform(dataset), columns=te.columns_)

# Sama seperti apriori, tetapi memakai FP-Tree di balik layar
freq = fpgrowth(df, min_support=0.4, use_colnames=True)
rules = association_rules(freq, metric="confidence", min_threshold=0.6)
print(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']])
